# 本地图源作为内置伪源接入图源列表

用户要在不安装任何 Extension 的情况下，从「图源」列表直接浏览 `localcomic` 里的本地漫画。我们决定把 Local source 做成图源列表中的内置伪源：

- 它不是 `manga_online_sources` 行，不由 Extension 提供，也不走扩展的启用 / 禁用与安装检查。
- 它固定排在所有扩展源与「已置顶」分组之上，没有置顶 / 排序 / 清除数据 / 卸载扩展菜单。
- 它使用自己的偏好开关（默认开启）；关闭后行保留、置灰、不可进入。
- 它不出现在 `enabledMangaOnlineSources` 的枚举结果里，因此不参与发现页来源磁贴、热门行与 Manga 全局搜索；它仍参与图源列表自身的搜索过滤。
- 行内容为开关、名称「本地图源」与 `localcomic` 的绝对路径（过长截断），不显示语言标签。

**Considered Options**

- **写入 `manga_online_sources` 当作普通 Source**：会进入扩展源枚举与发现 / 全局搜索，并继承扩展源的启用检查、置顶、清除数据、卸载扩展等生命周期；本地文件并不属于这些语义。
- **由 Extension 提供**：本地目录不是 Extension 的内容站点，还要为一个伪源维护扩展包与运行时依赖；没有扩展宿主时不可用，与「未安装扩展也能读取本地漫画」的目标冲突。
- **保留独立的「导入」子视图或设置入口**：入口与图源列表割裂，用户难以发现，也无法复用现有的源浏览页外壳、搜索与封面网格。
- **内置伪源行（选定）**：不落扩展源数据，复用现有源行与源浏览页组件，同时天然被排除在 `enabledMangaOnlineSources` 之外。

**Consequences**

- 本地图源不会出现在 Manga 全局搜索、发现页来源磁贴或热门行；在线与本地的搜索边界保持清晰。
- 内置伪源的生命周期与 Extension 源不同：只有启用开关，没有安装 / 卸载 / 清数据 / 排序动作。
- 图源列表的搜索框同时过滤内置行与扩展源，占位文案改为「搜索图源」。
- 未来若再需要不依赖 Extension 的来源，应沿用伪源模式，而不是把本地内容塞进扩展源表。

## Amendment 2026-11-08（local-source-polish，独立浏览页）

原「复用现有源行与**源浏览页组件**」中的源浏览页外壳一条，由本地图源的独立浏览页取代：本地图源页不再复用 `OnlineSourceBrowsePage` 的页面外壳（其列表 / 筛选 / 分页 / 空态机制），而是自己的页头（返回键 + 标题胶囊 + 「全部 / 未入架 / 已入架」页签 + 选择）、扫描封面网格与底部批量栏。**仍然复用**的是图源列表里的源行与启用开关、以及通用的 Fushi 组件（标题胶囊、分区页签、搜索栏、封面卡片、骨架 / 占位、批量栏、选择状态机与长按手势）。内置伪源的接入方式、禁用语义与「不出现在发现 / 全局搜索」等原决定不变；在线源浏览页继续使用原共享外壳，行为不变。
