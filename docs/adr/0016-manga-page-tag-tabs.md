# 漫画页以标签为单选页签，书架只收无标签漫画

漫画页顶部的用户标签原先是书架同款的彩色多选 chip：多个标签同时生效时结果取交集，用户无法把标签当成互斥分类使用；也没有一个固定的「未打标签」落点。我们决定把漫画页的标签栏改为与浏览页「图源 / 发现」同款的分段胶囊页签：

- 首项固定为「书架」，默认选中；其后是用户标签，顺序与标签管理页一致。应用运行期间保留当前选择，进程重启后回到「书架」；选择只作用于漫画页。
- 单选：任一时刻恰好一个页签生效；没有「全部」页签。
- 归属排他：「书架」= 没有任何用户标签的漫画；打过标签的漫画不出现在「书架」，只出现在对应的标签页签下；多标签漫画在每个对应标签页中都出现。
- 每个页签显示数量：数量是当前搜索、阅读状态与漫画下载筛选都生效后该页签会显示的漫画数，始终显示（包括 0）。标签名过长时截断，数字不截断。
- 页签栏不提供长按拖拽排序；标签顺序仍在标签管理页调整，页头「管理标签」入口保留。标签自身的颜色不参与呈现，选中只靠胶囊填充。
- 这些行为只用于漫画页；书籍 / 视频等其他媒体库的共享标签筛选仍保持彩色多选 chip 与拖拽排序。

**UI fidelity**：分段胶囊形态偏离 Fushi v3.0.0 原版的彩色 tag chip。这是用户在 2026-11-08/09 明确批准的 UI 改动，按 ADR 0008 的要求记录在此；实现复用浏览页已有的分段胶囊组件与主题，不引入新的视觉语言。

**Considered Options**

- **保留彩色多选 chip（现状）**：成本最低，但多标签取交集，无法把标签当互斥分类；没有固定的无标签落点。
- **增加「全部」页签**：能回到全量视图，但与「书架 = 无标签」的排他归属冲突，页签也不再互斥。
- **单选彩色 chip**：保留标签颜色，但用户要求向浏览页的分段胶囊看齐；标签颜色与选中填充会形成两套强调信号。
- **在页签栏内保留长按拖拽排序**：与单选胶囊的点击语义冲突，且排序已有标签管理页这个专用入口。
- **只改漫画页、其他媒体库保持多选**：共享筛选栏语义分叉，但避免破坏其他库的既有行为。

**Consequences**

- 给漫画打上任意标签即等于把它移出「书架」；只有去掉全部标签才会重新出现在「书架」。
- 各页签数量之和可能大于书架总数，因为多标签漫画在每个标签中各计一次。
- 搜索与筛选只在当前页签的集合内生效；数量承担「其他页签是否有命中」的提示，不再另加提示条。
- 选中的标签在标签管理页被删除时，页面回落到「书架」。
- 漫画页与共享标签筛选栏从此是两套呈现与状态模型，后续改动需分别验证。
