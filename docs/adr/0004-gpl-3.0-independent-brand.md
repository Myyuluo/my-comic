# GPL-3.0、独立品牌与明确署名

Fushi 以 GPL-3.0 分发；复制其代码会使 my-comic 成为 GPL-3.0 衍生作品。我们决定 my-comic 也使用 GPL-3.0、公开全部源码、保留 Fushi 及第三方组件的 license/版权声明，并使用独立品牌，在 README 和 About 中明确写明“基于 Fushi v3.0.0”。

**Consequences**

- 不能闭源分发；任何分发二进制都必须提供对应源码。
- 不使用 Mihon 的名称、logo 或 applicationId；只在描述性语境使用“Mihon-compatible”。
- 不内置、不托管任何扩展或默认扩展仓库。

## Amendment 2026-11-11（manga-history-branding-settings）

用户明确要求把 my-comic 作为独立产品发行，不再借用上游 Fushi 的版本号与发布线。本修订记录该产品身份：

- **应用版本**：应用从 `1.0.0` 起发行（构建元数据为 `1.0.0+1355`）；「设置 · 系统与关于 · 应用版本」显示精确版本名 `1.0.0`，不显示 build number。`1.0.0` 是独立发布线的起点，不是 Fushi v3.0.0 的延续。
- **仓库与品牌入口**：本项目的 GitHub 仓库是 `https://github.com/Myyuluo/my-comic`。左侧导航栏的品牌图标与「设置 · 通用 · GitHub」行都打开该仓库，不再指向 Fushi 官网或上游仓库。
- **更新源**：应用内更新检查只查询 `Myyuluo/my-comic` 的 GitHub Releases，不保留指向上游 `hajisensai/fushi` 的回退。仓库没有可用 release（404、空列表或无匹配通道）时按「已是最新」处理：不报错，也不把上游 3.x 发布视为本应用的更新。
- **上游关系不变**：代码基线仍是冻结的 Fushi v3.0.0 快照（ADR 0001 / ADR 0003），GPL-3.0 授权与「基于 Fushi v3.0.0」的署名不变。本修订只确定产品身份与发布线，不引入上游合并或上游更新跟随。

**Considered Options**

- **继续沿用 Fushi 3.x 版本号与上游 release 作为更新源**：用户会收到不属于本产品的上游更新，且与独立品牌矛盾。
- **保留上游仓库作为更新回退**：上游 3.x 对 1.0.0 会被判为新版本，正好回到本修订要消除的问题。
- **没有 release 时报错或提示检查失败**：仓库尚无 release 属正常状态，报错会让用户误以为更新功能坏了；决定按「已是最新」处理。
