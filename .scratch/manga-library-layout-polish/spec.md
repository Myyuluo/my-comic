# 漫画页布局跟进：标签栏下移、继续阅读胶囊与暂停按钮样式（manga-library-layout-polish）

Status: implemented
Date: 2026-11-09

## Problem Statement

漫画页当前的顶部布局把「漫画」标题、标签页签胶囊和右上角动作挤在同一行；继续阅读仍是一张占满网格顶部的大卡片。用户希望：

- 标签分类（书架 + 用户标签）离开顶部动作行，挪到「漫画」标题下方，成为一行更轻的二级胶囊（参考图一：`媒体库 / 发现 / …` 下面那行 `首页 / 系列 / 全部视频`）。
- 继续阅读不要再占网格顶部的大卡片，而是变成顶部行里的一枚紧凑胶囊（参考图三：圆形封面 + 蓝色「继续阅读」+ 蓝色播放圆钮），放在标签栏原来的位置。
- 下载页的「全部暂停 / 全部继续」按钮改成图二的样式（`开始串流` 那种浅蓝胶囊按钮），而不是上一轮自定义的灰色页头胶囊。

## Solution

- 标签栏移到标题下方的二级浮动胶囊行，保留「书架固定最左 + 标签 + 单选 + 排他归属 + 数量」的全部语义与筛选行为，视觉改用参考图的二级胶囊形态，随滚动与主 chrome 行一起收放。
- 继续阅读入口改为顶部 chrome 行里的紧凑胶囊：圆形封面 + 蓝色「继续阅读」+ 蓝色播放圆钮，不显示书名与进度；整颗可点击，无继续阅读条目时隐藏；网格顶部的旧大卡片移除。
- 下载页的全局暂停按钮改用 `FushiFloatingTextAction` 的默认浅蓝胶囊样式，保留暂停/播放图标与文字、状态机、位置与 key。
- 同步更新 GLOSSARY 与 ADR 0016 的布局说明。

## User Stories

1. 作为漫画读者，我希望标签分类显示在「漫画」标题下方，而不是和标题、动作挤在同一行，以便顶部更清爽。
2. 作为漫画读者，我希望标签行使用参考图的二级胶囊形态，以便视觉层级与其它库页一致。
3. 作为漫画读者，我希望标签行仍然以「书架」为第一项并固定在最左，以便随时回到默认页签。
4. 作为漫画读者，我希望标签行每次只能选中一个页签，以便按标签互斥分类浏览。
5. 作为漫画读者，我希望「书架」只显示没有用户标签的漫画，有标签的漫画只出现在对应标签下。
6. 作为漫画读者，我希望多标签漫画在它的每个标签页签下都出现。
7. 作为漫画读者，我希望每个页签仍显示漫画数量，以便知道每个分类的规模。
8. 作为漫画读者，我希望数量用更轻的次要色小号数字呈现，以便不抢标签名的视觉。
9. 作为漫画读者，我希望标签多到放不下时在胶囊内横向滚动，「书架」保持可见。
10. 作为漫画读者，我希望标签行随主 chrome 行一起向下滚动收起、向上滚动弹回。
11. 作为漫画读者，我希望「管理标签」仍然在右上角动作组里，以便新建、改名、删除和排序标签。
12. 作为漫画读者，我希望搜索、阅读状态筛选和漫画下载筛选仍然只在当前标签页签的集合内生效。
13. 作为漫画读者，我希望继续阅读入口变成顶部行里的一枚紧凑胶囊，以便不占网格空间。
14. 作为漫画读者，我希望胶囊显示当前继续阅读作品的圆形封面，以便一眼认出是哪部漫画。
15. 作为漫画读者，我希望胶囊显示蓝色的「继续阅读」文字，以便知道点它会继续阅读。
16. 作为漫画读者，我希望胶囊右侧有蓝色圆形播放钮，以便有明确的动作提示。
17. 作为漫画读者，我希望胶囊不显示书名和进度，以便保持参考图的紧凑形态。
18. 作为漫画读者，我希望点击胶囊任意位置都能继续阅读，而不必精确点中播放钮。
19. 作为漫画读者，我希望悬停胶囊时能看到书名 tooltip，以便确认作品但不破坏紧凑视觉。
20. 作为漫画读者，我希望没有继续阅读条目时整个胶囊隐藏，只保留「漫画」标题与右侧动作。
21. 作为漫画读者，我希望网格顶部不再有旧的继续阅读大卡片，以免出现两个继续阅读入口。
22. 作为漫画读者，我希望继续阅读胶囊随主 chrome 行一起收起/弹回。
23. 作为漫画读者，我希望窄窗放不下时顶部中间区域可以横向滚动，胶囊不消失，右侧动作按现有规则收进「⋯」。
24. 作为漫画读者，我希望胶囊点击后仍走原来的继续阅读逻辑（选中章节/页），不改变续读落点。
25. 作为漫画读者，我希望下载页的「全部暂停 / 全部继续」按钮使用参考图的浅蓝胶囊样式，以便与其它悬浮操作一致。
26. 作为漫画读者，我希望按钮同时有暂停/播放图标和文字，以便一眼看出当前动作。
27. 作为漫画读者，我希望按钮的文字仍是「全部暂停 / 全部继续」，并随队列状态切换。
28. 作为漫画读者，我希望按钮仍在下载页右下角，且不遮挡最后一张任务卡。
29. 作为漫画读者，我希望按钮的点击行为、状态机和 key 不变，以便现有自动化与习惯不受影响。
30. 作为漫画读者，我希望标签数量、单选与筛选行为完全不变，只改变位置与视觉。
31. 作为漫画读者，我希望这些改动复用现有组件与主题，以便界面仍然熟悉。
32. 作为漫画读者，我希望 GLOSSARY 能准确描述新的布局：标签栏在标题下方，顶部行是继续阅读胶囊。
33. 作为漫画读者，我希望 ADR 记录这次布局调整，以便未来读者理解为什么标签栏不再占顶部页签位。

## Implementation Decisions

### 标签栏

- 标签栏不再登记到主 chrome 行的页签位；改为标题下方的**二级浮动行**，复用现有二级胶囊行（`LibrarySectionTabs(secondary: true, floating: true)`）的视觉与收放行为。
- 主 chrome 行保留「漫画」标题与右上角动作；顶部页签位让给继续阅读胶囊。
- 语义完全不变：`书架` 固定最左、其后用户标签、单选、排他归属、多标签归属、按当前搜索/阅读状态/漫画下载筛选计算的数量。
- 数量保留，使用更轻的次要色小号数字嵌在胶囊里；标签名截断时数字不截断。
- 标签行在胶囊内横向滚动，`书架` 固定可见；「管理标签」入口仍只在右上角动作组。
- 二级行与主 chrome 行共用同一套显隐/滚动收放（与浏览页的二级行同源），不新增一套滚动状态。

### 继续阅读胶囊

- 放在主 chrome 行、标签栏原来的位置（「漫画」标题右侧、右上角动作左侧），随主 chrome 行收起/弹回。
- 形态严格按参考图：圆形封面缩略图 + 主色蓝「继续阅读」文字 + 主色蓝圆形播放钮（白色播放图标）；不显示书名与进度。
- 整颗胶囊可点击，点击走现有继续阅读打开路径；播放钮只是视觉强调。悬停 tooltip 显示书名。
- 没有继续阅读条目时整个胶囊不渲染；网格顶部的旧继续阅读大卡片移除，胶囊是该页面唯一的继续阅读入口。
- 窄窗放不下时，主 chrome 行的中间区域可横向滚动，胶囊保持可见；右侧动作按现有 `FushiFloatingChromeBar` 规则收进「⋯」。
- 复用现有封面解析/缓存、悬浮胶囊底色与前景色；不引入新的视觉语言。

### 下载页全局按钮

- 改为 `FushiFloatingTextAction` 的默认样式：`secondaryContainer` 底、`onSecondaryContainer` 前景、stadium 圆角、柔和投影。
- 保留暂停/播放图标 + 粗体文字「全部暂停 / 全部继续」；位置仍在右下角，列表底部留白不变。
- 状态机（空列表隐藏 / 全部暂停或失败显示全部继续 / 其余显示全部暂停）、点击行为、key 均不变。
- 移除上一轮自定义的 `surfaceContainer` 底色与前景覆写。

### 文档

- `GLOSSARY.md`：
  - 更新 **View tab（视图页签）**：漫画页顶部不再是标签栏；顶部 chrome 行是继续阅读胶囊，标签栏在标题下方的二级行。
  - 更新 **Tag / 书架页签**：补充二级浮动胶囊行的呈现位置与数量样式。
  - 新增 **继续阅读胶囊（Continue reading pill）**。
- `docs/adr/0016-manga-page-tag-tabs.md` 补一条修订说明：标签页签栏从顶部 chrome 行移到标题下方二级行；顶部行改由继续阅读胶囊占据。

## Testing Decisions

- 好测试：只断言用户可见的公开行为（哪一行渲染了什么、点选后的筛选结果、胶囊是否存在/可点、按钮的可见样式与状态切换），不扫描源码、不调用私有方法、不断言内部实现细节。
- 使用现有页面级 seam，不新增测试专用接口。

1. **漫画页（壳 + 书架页）**：`MangaLibraryPage` / `ReaderFushiHistoryPage` 页面级 widget。
   - 标签栏位于标题下方的二级浮动行，不在主 chrome 行的页签位；`书架` 固定、数量、单选、排他归属、多标签归属保持。
   - 主 chrome 行显示继续阅读胶囊：圆形封面 + 「继续阅读」+ 播放钮；无历史时隐藏；网格顶部不再有旧 hero。
   - 点击胶囊触发继续阅读打开路径。
   - 既有搜索/筛选/标签测试同步更新。
   - prior art：`manga_library_tags_in_chrome_test`、`manga_library_tag_tabs_test`、`manga_library_search_and_download_filter_test`。
2. **下载页**：`DownloadsPage` + 真实下载服务（内存 DB）。
   - 全局按钮使用 `FushiFloatingTextAction` 默认样式（`secondaryContainer` 底）；保留图标 + 文字、key、状态机与位置。
   - 既有全局暂停/继续测试继续通过。
   - prior art：`downloads_page_test`。
- 文档改动不需要测试。

## Out of Scope

- 标签语义改动（单选、排他归属、多标签归属已实现）。
- 下载页暂停/继续状态机改动。
- 上一轮暂缓的「标签挪到右下角」「继续阅读卡缩到 50%」方案。
- 标签颜色、新的视觉语言或新的共享组件体系。
- 移动端专属布局，除窄窗时的横向滚动规则外。
- 用户偏好迁移或新的持久化设置。

## Further Notes

- 图片映射：**图一** = 二级胶囊行（`媒体库 / 发现 / …` 下面那行）→ 标签栏；**图二** = `开始串流` 浅蓝胶囊按钮 → 下载页全局按钮；**图三** = 带圆形封面与蓝色播放钮的「继续阅读」胶囊。
- 这次布局调整是用户明确批准的 UI 改动，仍受 ADR 0008 的 UI fidelity 约束：复用现有组件与主题，不引入新视觉语言。
- 继续阅读胶囊复用现有 hero 的作品选择与打开路径，不新增续读逻辑；旧 hero 只是从网格顶部移除。
- 标签行与继续阅读胶囊同时位于浮动 chrome，内容顶部让位需要同时计入两行（与现有二级行机制同源），避免首行被遮挡。
- 建议工单拆分：01 标签栏二级行；02 继续阅读胶囊；03 下载页按钮样式；04 GLOSSARY + ADR。
