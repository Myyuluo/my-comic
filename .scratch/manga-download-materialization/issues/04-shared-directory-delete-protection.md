# 04: 共享目录的删除保护与空目录清理

**What to build:** 删除作品 A 的章节不影响共享目录里作品 B 的章节；空目录只在没有任何作品引用时清理；章名冲突使用短哈希/扫译组后缀而不是 `(2)`；旧遗留目录不自动删除。

**Blocked by:** 03（同名作品共享下载目录）

**Status:** ready-for-agent

- [ ] 批量删除与单章删除只删除目标作品自己映射的容器。
- [ ] 删除作品 A 的最后一章不会删除共享目录或作品 B 仍在使用的文件。
- [ ] 空的 manga 目录清理前检查所有引用该目录的作品；整个 source 目录也空了才删除 source 目录。
- [ ] 章名冲突使用短哈希或扫译组后缀，不出现 `(2)`。
- [ ] 旧版本遗留的封面目录、随机字符串目录不自动删除。
- [ ] 服务级与页面级测试覆盖共享目录删除、空目录清理、章名冲突；`flutter analyze` 与 Windows 构建通过。
