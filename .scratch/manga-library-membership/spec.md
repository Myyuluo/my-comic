# 书架归属、非书架作品与下载索引（manga-library-membership）

Status: ready-for-agent
Date: 2026-11-10

## Problem Statement

漫画读者在“书架 / 非书架 / 下载 / 历史”之间反复切换时，遇到一组互相牵连的问题：

1. 导入 `.tachibk` 后，History 页的导入记录显示灰色封面；部分卡片标题显示 `fushi://book/<bookKey>`；点击无法阅读。
2. 下载页的失败任务只有“重试”，没有取消；用户无法清掉失败队列。
3. 同一部在线漫画反复移出/加入书架并重新下载时，`downloads` 下会出现 `异种族相亲档 (2)`、`瓶中女巫 (2)` 等重复文件夹。
4. 已经从 `downloads` 下载过的作品，移出书架后再加入，详情页不显示已下载章节；直接去在线源看同一部漫画也不显示已下载。
5. 在线源点章节阅读会静默把作品加入书架；用户只想要“阅读”，不想要“入库”。
6. 未加入书架的在线漫画没有章节下载、标记已读等功能。
7. 导入 `.tachibk` 后，如果 `downloads`/`local` 中已有对应文件，详情页不显示已下载。
8. 「重建下载索引」没有按用户设想工作：它不能可靠地把 `downloads`/`local` 中的文件同步到已有书架作品。

根因是 MyComic 把“Manga 行存在”等同于“在书架中”。Mihon v0.21.3 不是这样：非书架 Manga 也持久化，`favorite=false`；阅读、已读、进度、History、下载都基于这些行；移出书架只清 favorite，保留章节、已读、进度、下载。MyComic 需要引入等价的 **Library membership** 模型。

## Solution

- 给 Manga 记录增加 Library membership；非书架作品也持久化 Manga/Chapter 行。书架、Home 继续阅读、备份“书架”、更新探测、Tag、订阅、导出按 membership 过滤；阅读、进度、已读、History、下载使用所有 Manga 行。
- 移出书架只清 membership，移除 Tag 与订阅，保留章节、已读、进度、下载与 History；「同时删除本地文件/统计数据」仍保留。本地图源同样非破坏；勾选删除本地文件时连行与状态一起删除。
- 在线源阅读不再自动加入书架；会创建/复用非书架行。非书架作品可阅读、标记已读/未读/此章及更早、保存进度、继续阅读、下载/删除下载、写 History/统计；下载后可提示“加入书架？”。Tag、订阅/自动追更、Tracking 仍仅限书架。
- 下载文件夹按 `pages.json` 的 Manga 身份复用；无 manifest 时保持 `(2)` 安全规则；复用后重新关联章节。
- 详情页的已下载状态不再要求 Library 行；书架与在线源未入架作品都能显示已下载。`local` 中带 manifest 的文件夹可关联到在线 Manga，不做标题匹配。
- 失败下载行增加「取消」：删除任务与 staging/临时文件；保留「重试」。
- 导入写 canonical History 身份与完整快照；历史页兼容旧裸快照；封面回退到快照/来源封面 URL。
- 导入后自动 re-link 已有 `downloads`/有 manifest 的 `local` 文件到已导入 Manga；「重建下载索引」仍是手动全量扫描。
- 「清理数据库」按 Mihon 对齐：Source 多选、默认保留有阅读记录的作品、删除所选 Source 的非书架行、只删除被清理作品的 History；保留书架作品/History、磁盘文件、设置与源。

## User Stories

### Library membership 与非书架作品

1. 作为漫画读者，我希望打开在线源作品页时创建一条“非书架”Manga 记录，以便后续阅读、已读、进度、下载与 History 有稳定归属。
2. 作为漫画读者，我希望非书架作品不出现在漫画书架页签，以便书架只显示我主动加入的作品。
3. 作为漫画读者，我希望非书架作品不出现在 Home「继续阅读」，以便首页仍聚焦书架。
4. 作为漫画读者，我希望非书架作品的阅读进度、已读标记、下载与 History 持久化，以便关闭应用后仍然保留。
5. 作为漫画读者，我希望非书架作品通过 History 与在线源作品页继续阅读，以便仍然能找到它们。
6. 作为漫画读者，我希望从历史或在线源再次打开同一作品时复用同一条非书架记录，以便不会重复建行。
7. 作为漫画读者，我希望显式「加入书架」只是把已有非书架记录翻转为书架归属，以便 uid、阅读状态、下载目录都不变。
8. 作为漫画读者，我希望加入书架时仍可选择 Tag，以便归类。
9. 作为漫画读者，我希望非书架作品不能添加 Tag，以便 Tag 语义仍属于书架。
10. 作为漫画读者，我希望非书架作品不能订阅/自动追更，以便订阅语义仍属于书架。
11. 作为漫画读者，我希望非书架作品不参与书架更新探测，以便不会为未收藏作品自动下载新章。
12. 作为漫画读者，我希望备份的「书架中的作品」只导出书架作品，以便不会把非书架作品误导出为 Library 条目。
13. 作为漫画读者，我希望备份的「所有已读作品」仍能把非书架已读作品导出为 `favorite=false`，以便完整保留阅读记录。
14. 作为漫画读者，我希望书架页签计数、Tag 页签计数只统计书架作品，以便数字与可见内容一致。
15. 作为漫画读者，我希望非书架作品不会因为 Tag 页签或书架筛选而消失，以便源页和 History 始终能打开它。

### 移出书架

16. 作为漫画读者，我希望移出书架只清除书架归属，不移除 Manga/Chapter 记录，以便之后还能阅读、下载与查看 History。
17. 作为漫画读者，我希望移出书架保留阅读进度与已读标记，以便重新加入后继续阅读。
18. 作为漫画读者，我希望移出书架保留已下载章节与下载索引，以便重新加入后立即显示已下载。
19. 作为漫画读者，我希望移出书架保留 History，以便阅读记录不因书架状态改变而丢失。
20. 作为漫画读者，我希望移出书架移除 Tag 分配与订阅，以便未收藏作品不再带有书架专属状态。
21. 作为漫画读者，我希望移出书架仍可选择「同时删除本地文件」，以便需要时释放磁盘。
22. 作为漫画读者，我希望在线作品删除本地文件后仍保留非书架行与阅读状态，以便之后可重新下载。
23. 作为漫画读者，我希望移出书架仍可选择「同时删除统计数据」，以便清理阅读统计。
24. 作为漫画读者，我希望本地图源作品移出书架时不删除原作文件，以便文件仍归我所有。
25. 作为漫画读者，我希望本地图源作品勾选「同时删除本地文件」时连 Manga 行与状态一起删除，以便不留下指向已删除文件的孤儿。
26. 作为漫画读者，我希望移出弹窗文案明确“进度/已读/下载会保留”，以便不会误以为移出等于删除。
27. 作为漫画读者，我希望不新增独立的“彻底删除漫画”动作，以便使用现有移出选项即可。
28. 作为漫画读者，我希望移出后重新加入复用同一条记录与同一文件夹，以便不产生 `(2)` 文件夹。
29. 作为漫画读者，我希望移出后再从在线源打开同一作品时识别为已有非书架记录，以便不会重复入库。
30. 作为漫画读者，我希望批量移出多个作品时逐作品应用上述语义，以便批量操作一致。

42. 作为漫画读者，我希望提示不是自动加入，以便保持主动选择。

49. 作为漫画读者，我希望重新加入同一作品时复用已有的 `downloads/<来源>/<漫画>` 文件夹，以便不再生成 `(2)`。

### 文档与 UI

109. 作为漫画读者，我希望移出弹窗文案、清理数据库文案与新增提示符合现有 Fushi 设计语言，以便界面一致。
110. 作为漫画读者，我希望非书架作品的“加入书架？”提示不遮挡阅读，以便体验顺畅。
111. 作为漫画读者，我希望新增/修改的 UI 不改变 ADR 0008 的 Fushi 组件、主题与布局语言，以便审美一致。

## Implementation Decisions

### Library membership 与非书架行

- 在 Manga 记录上增加 Library membership（布尔，默认 true 用于迁移）；`membership=false` 表示非书架作品。`format='manga'` 不再是书架归属的判据。
- 打开在线源作品页时确保存在一条非书架 Manga 行（membership=false）并写入章节；仅在需要时创建，不在源列表阶段批量建行。
- 非书架行的 `uid` 在首次插入时生成；显式加入书架翻转同一行的 membership，不新建行，不改变 `bookKey`/`uid`/`extractDir`。
- 集中定义 membership 判据，并审计所有读取点：
  - 书架页、Tag 页签计数、Home 继续阅读、书架排序/筛选、书架批量动作。
  - 备份「书架中的作品」、更新探测、订阅/自动追更、Tag 分配、书架的已读/完成统计。
  - 其余读取点（阅读器、章节状态、History、下载、下载索引、重建、源页、导入去重）使用所有 Manga 行。
- 非书架行不进入 Tag/订阅/Tracking 的入口；加入书架后才可用。
- 本地图源作品仍按现有静默登记进入书架；移出后采用非破坏 membership=false（Q11 A），本地源页面把已有行显示为非书架作品。

### 移出书架

- 移出书架只把 membership 置 false；保留 Manga/Chapter、阅读进度、已读标记、下载任务/映射、下载文件夹与 History。
- 同时移除该作品的 Tag 分配与订阅/自动追更标志。
- 保留「同时删除本地文件」与「同时删除统计数据」选项：
  - 在线作品：勾选删除文件时删除已下载文件与下载索引，但保留非书架行与阅读状态，之后可重新下载。
  - 本地图源作品：勾选删除文件时删除 Manga 行与阅读/已读/下载状态（Q14 A）；不勾选时保留非书架行与状态。
  - 统计数据删除沿用现有语义。
- 不再新增独立的“彻底删除漫画”动作；现有移出选项足够。
- 移出弹窗文案改为“只移出书架；阅读进度、已读标记、已下载章节与 History 会保留”，两个删除选项的提示保持破坏性说明。
- 批量移出逐作品应用同一语义；部分失败保留作品并报告。

### 在线阅读与非书架功能

- 在线源章节点击不再调用“加入书架”，而是确保/复用 membership=false 行并打开阅读器。
- 阅读器对非书架行正常工作：阅读进度、章节已读、当前章节、History、统计都写入该行/uid；不需要 Library 行。
- 非书架作品开放：下载/删除下载、标记已读/未读/此章及更早、批量标记、阅读进度与继续阅读、History/统计、刷新/登录/打开网站。
- 非书架作品不开放：Tag、订阅/自动追更、Tracking；下载完成后显示可选「加入书架？」提示（不自动加入）。
- 本地图源阅读仍静默登记（保持现状）。
- Home 继续阅读仍只显示 membership=true 的作品；非书架通过 History 与源作品页继续阅读。
- 加入书架：若存在非书架行则翻转 membership；否则创建书架行。加入时仍走 Tag 选择器；订阅入口随后出现。

### 下载身份、文件夹与已下载状态

- 统一下载身份为 `(runtime, 数字 sourceId, seriesKey/mangaKey)`；扩展包作为 tie-breaker，`mihon.unavailable` 与真实包视为同一身份（数字 sourceId + series key 容忍）。
- 文件夹复用：在目标 Source 目录下读取每个 Manga 文件夹及其章节（目录或 `.cbz`）的 `pages.json`；恰好一个匹配 → 复用该文件夹；多个匹配 → 不猜，保持冲突/`(2)`；无 manifest → 保持现有 `(2)` 安全规则。
- 复用后立即调用共享的 re-link 逻辑，重建该作品的 `manga_chapter_dirs`，使详情页显示已下载。
- 已下载状态不再要求 Library 行：详情页以 entry 身份查询下载索引；无行时扫描 `downloads` 与 `local` 的 manifest 身份；`local` 中带 manifest 的文件夹可关联到在线 Manga。
- 不做标题匹配（无 manifest 的 `local` 不关联）。
- 共享一个 scanner/identity predicate，folder resolution、series page、download service、rebuild 不再各自重复实现。
- 已有 `(2)` 重复文件夹不自动删除/合并；重建报告并优先 recorded `extractDir`/最新完整副本，否则跳过。

### 失败下载

- 失败下载行同时显示「重试」与「取消」。
- 取消删除任务行、`.staging/<jobId>`、`.cbz.tmp`，并清理可能存在的映射容器；不弹确认，完成后 toast。
- 保留现有「重试」语义；ADR 0017 更新。

### 导入与 History

- 导入 `favorite=true` 的书架作品：创建 membership=true 行（现有行为）。
- 导入 `favorite=false` 的已读作品：创建 membership=false 行，写入章节、阅读进度、已读与 History；不进入书架。
- 导入 History 使用 canonical `manga_online` 身份（或本地作品的 canonical 身份）与完整 `mangaHistory` 快照（title/author/imageUrl/online/bookKey/mihon_history）。
- History 读取兼容旧裸快照 `{title,author,imageUrl,mihon_history}`：按 bookKey 回退匹配、解析旧快照、从 Library 行/快照补 online 信息。
- History 封面回退：本地封面 → 快照 imageUrl → sourceMetadata `series.coverUrl` → 占位。
- 历史卡片标题优先 Library 显示标题 → 快照标题 → 清晰降级文案；不显示原始 `fushi://book/...`。
- 导入后自动对已导入 Manga 执行下载匹配：读取 `downloads` 与带 manifest 的 `local`，按身份复用文件夹并写映射；不额外创建 Library 条目；重建按钮仍是全量手动扫描。
- 导入报告增加下载匹配/跳过计数；重复导入幂等。

### 重建下载索引

- 强制扫描 `downloads` 与 `local`；`autobackup` 不扫描。
- 先按 `pages.json` 身份 re-link 所有已有 Manga 行（membership true/false 都处理）；身份匹配不到时回退文件名。
- `local` 中带 manifest 的文件夹可关联到在线 Manga；无 manifest 不做标题匹配。
- 保留 orphan recovery：为未索引的 `downloads`/`local` 内容补建条目（现有语义）。
- 重复副本优先 recorded `extractDir` 或最新完整副本；无法决定时跳过并报告，不猜。
- 不删除、不重命名文件或映射。
- 完成后通知已打开的详情页刷新已下载状态（watch 映射表或服务 revision）。
- 报告匹配/跳过/歧义/失败数量。

### 清理数据库

- 设置项改名为「清理数据库」。
- 确认界面：
  - 列出有非书架记录的 Source 及数量，可多选。
  - 默认开启「保留有阅读记录的作品」；关闭时警告已读/进度会丢失。
  - 显示将删除的作品/History 数量。
- 执行：
  - 删除所选 Source 下 membership=false 的 Manga 行及其章节、阅读状态、已读、下载任务/映射、合集关联；磁盘文件保留。
  - 开关开启时保留任何有已读章节或阅读进度的非书架作品。
  - 只删除被清理作品对应的 History；保留书架作品 History。
  - 清理无归属的阅读状态行（现有语义）。
  - 保留书架作品、书架 History、设置、源、扩展、下载文件、Local source 文件。
- 进度框 + toast 结果；无需重启。
- 不等同于恢复出厂设置。

## Testing Decisions

  2. 备份 fixture/import-service seam（合成 `.tachibk` + 真实 DB）：导入成员归属、History 身份/快照、`favorite=false` 行、下载自动匹配。

  - 非书架功能：阅读/进度/已读/批量标记/下载/删除下载/继续阅读/History/统计；Tag/订阅/Tracking 不可用；下载后提示。
  - 文件夹/状态：manifest 身份复用；无 manifest `(2)`；多匹配不猜；CBZ manifest；复用后 re-link；源页/书架页非书架已下载；`local` manifest 关联；无标题匹配。
  - 失败取消：失败行动作、任务/临时文件清理、toast、其他任务不受影响。
  - 历史：canonical 导入、旧快照兼容、封面回退、点击打开、旧行不删。
  - 导入：`favorite=false` 行、History、自动下载匹配、幂等、报告。
  - 重建：全量扫描、身份/文件名回退、本地 manifest、orphan recovery、重复优先/skip、报告、页面刷新。
