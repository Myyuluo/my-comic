# 08: 非书架下载与删除下载

**What to build:** 让 membership=false 的在线作品支持下载章节、下载全部与删除已下载章节；下载 worker 与下载索引能解析非书架行/身份；下载任务出现在下载页；下载完成后触发可选的「加入书架？」提示。

**Blocked by:** 07（已下载状态脱离书架）

**Status:** ready-for-agent

- [ ] 非书架作品可下载单个章节与全部章节。
- [ ] 非书架作品的下载任务出现在下载页，支持暂停/恢复/取消/重试。
- [ ] 下载 worker 与下载索引能解析非书架行或下载身份，不需要 Library 行。
- [ ] 非书架作品可删除已下载章节并释放文件/映射。
- [ ] 下载完成后显示可选「加入书架？」提示，不自动加入。
- [ ] 下载与删除下载后详情页状态立即更新。
- [ ] 页面级与服务测试覆盖非书架下载、任务、删除与提示。
