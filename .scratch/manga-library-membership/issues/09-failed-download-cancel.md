# 09: 失败下载取消

**What to build:** 下载页的失败任务同时提供「重试」与「取消」。取消删除任务行、`.staging` 与 `.cbz.tmp`（以及可能存在的映射容器），不弹二次确认，完成后 toast；其他任务不受影响。

**Blocked by:** None（can start immediately）

**Status:** ready-for-agent

- [ ] 失败下载行同时显示「重试」与「取消」两个动作。
- [ ] 取消删除任务行与 `.staging/<jobId>`、`.cbz.tmp`，并清理可能存在的映射容器。
- [ ] 取消不弹二次确认，完成后显示 toast。
- [ ] 取消不影响队列中的其他任务或已完成章节。
- [ ] 重试仍保持现有语义。
- [ ] ADR 0017 的记录同步更新。
- [ ] 页面级与服务测试覆盖失败行动作、文件清理、toast 与其他任务不受影响。
