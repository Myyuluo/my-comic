## Answer

实现提交：`d611ba63`（feat(manga): non-library reading features and add-to-shelf prompt (ticket 05)），后续 `1e35347d` 收敛提示频率。

- **阅读标记与进度：** 非书架行沿用既有的章节已读/未读、此章及更早、批量已读/未读动作；状态写入与书架行相同的持久化路径，重开页面后仍保留。
- **继续阅读：** 续读按钮对非书架作品可用，按上次阅读记录回到对应章节与页码，不再要求作品在书架中。
- **其他动作：** 刷新章节、登录源、打开网站对非书架作品保持可用（与书架作品一致）。
- **隐藏入口：** 非书架作品的 Tag、订阅/自动追更、Tracking 入口不渲染；加入书架后订阅入口出现（现有 membership 页面测试覆盖）。
- **加入书架提示：** 页面打开期间观测到下载任务从非 done 变为 done、且作品仍非书架成员时，显示非模态 SnackBar「加入书架？」，带可选操作按钮；只有用户点击才按现有 `_addToLibrary` 翻转同一行的 membership，绝不自动加入。提示在每次打开作品页最多出现一次（批量逐章完成不重复打扰），且仅在观测到状态跃迁时出现，打开页面前已下完的章节不追问。
- **Home 继续阅读：** 仍只显示书架作品，继续由既有 membership 页面测试保障。
- **测试：** `fushi/test/pages/manga_nonlibrary_reading_test.dart` 覆盖各动作与持久化、续读、入口隐藏/加入后出现、下载完成提示与不自动加入、每次访问仅提示一次；与 `manga_series_page_downloaded_status_test.dart`、`manga_series_page_phase_c_test.dart`、`manga_library_membership_test.dart`、`i18n_keys_sorted_guard_test.dart` 一并通过（38 tests）。
