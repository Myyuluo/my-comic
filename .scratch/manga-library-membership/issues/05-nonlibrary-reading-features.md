# 05: 非书架阅读功能

**What to build:** 让非书架在线作品拥有除 Tag、订阅/自动追更、Tracking 之外的书架级章节功能：标记已读/未读/此章及更早、批量标记、继续阅读、刷新/登录/打开网站；下载完成后显示可选的「加入书架？」提示。Home 继续阅读仍只显示书架作品。

**Blocked by:** 02（非书架行与在线阅读）

**Status:** ready-for-agent

- [ ] 非书架作品支持标记已读/未读/此章及更早，并持久化。
- [ ] 非书架作品支持批量标记已读/未读。
- [ ] 非书架作品支持继续阅读并回到上次章节/页。
- [ ] 非书架作品支持刷新章节、登录源、打开网站。
- [ ] 非书架作品不显示 Tag、订阅/自动追更、Tracking 入口。
- [ ] 非书架作品下载完成后出现可选「加入书架？」提示，不会自动加入。
- [ ] Home 继续阅读仍只显示书架作品。
- [ ] 页面级测试覆盖各动作、状态持久化、入口隐藏与提示。
