# 02: 非书架行与在线阅读

**What to build:** 打开在线源作品页时创建或复用一条 membership=false 的 Manga 行与章节；点章节不再自动加入书架，而是直接在阅读器中打开该非书架行。阅读进度、章节已读、当前章节、History 与阅读统计写入这条行，书架不受影响。

**Blocked by:** 01（Library membership 基础）

**Status:** ready-for-agent

- [ ] 打开在线源作品页时创建或复用一条非书架 Manga 行，包含章节与来源 metadata。
- [ ] 点章节阅读不再自动加入书架，阅读器可打开非书架行。
- [ ] 阅读进度、章节已读、当前章节、History 与阅读统计持久化到该非书架行/uid。
- [ ] 书架、Home、Tag 计数不出现该非书架作品。
- [ ] 再次从在线源或 History 打开同一作品时复用同一行/uid，不重复建行。
- [ ] 本地图源点章节仍静默登记，行为不变。
- [ ] 页面级测试覆盖创建/复用、无自动入库、进度/History 持久化与书架隔离。
