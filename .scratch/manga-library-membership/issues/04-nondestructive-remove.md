# 04: 非破坏移出书架

**What to build:** 移出书架只清 membership，保留 Manga/Chapter、阅读进度、已读标记、下载任务/映射、下载文件夹与 History；同时移除 Tag 分配与订阅。保留「同时删除本地文件」与「同时删除统计数据」选项：在线作品删文件但保留非书架行/状态；本地作品勾选删文件时连行/状态一起删除。弹窗文案与批量语义同步调整。

**Blocked by:** 01（Library membership 基础）、02（非书架行与在线阅读）

**Status:** ready-for-agent

- [ ] 在线与本地作品移出书架后 membership=false，Manga/Chapter、阅读进度、已读、下载与 History 保留。
- [ ] 移出后 Tag 分配与订阅/自动追更被移除。
- [ ] 在线作品勾选「同时删除本地文件」时删除已下载文件与下载索引，但保留非书架行与阅读状态。
- [ ] 本地图源作品勾选「同时删除本地文件」时删除 Manga 行及阅读/已读/下载状态。
- [ ] 「同时删除统计数据」保持现有语义。
- [ ] 移出弹窗文案说明“进度/已读/下载会保留”，两个删除选项仍为破坏性说明。
- [ ] 不新增独立的“彻底删除漫画”动作。
- [ ] 批量移出逐作品应用同一语义，部分失败保留并报告。
- [ ] 页面级测试覆盖在线/本地、两个选项、Tag/订阅移除、行/状态保留与批量。
