# 08: 历史记录写入与历史页基础

**What to build:** 主导航新增「历史」一级页面；打开章节进入阅读器时写入/更新一条历史；历史页以网格展示、点击进入作品页、无痕阅读不写入。

**Blocked by:** None（can start immediately）

**Status:** ready-for-agent

- [ ] 新增 `HomeTab` 值「历史」，导航可见列表固定插在「浏览」之后、「下载」之前；补齐图标/标签、页面挂载、外壳标题与控制通道页签名。
- [ ] 历史页以 `media_open_history` 为唯一数据源；不读取 `reader_positions.updatedAt` 作为历史页来源。
- [ ] 打开章节进入阅读器时（作品页开章、首页继续阅读直接开书、阅读器内切章）写入/更新历史；只打开作品详情页不写。
- [ ] 每部 Manga 一条，重复阅读更新 `openedAt` 并置顶。
- [ ] 身份为「Source + 作品 id」；本地图源使用本地伪源 + 相对路径；同一作品加入书架后仍只有一条，渲染优先使用 Library 最新标题与封面。
- [ ] 未入书架的在线作品也写入历史，`snapshotJson` 保存 source id、作品 id、URL、标题、封面；点击时可打开来源作品页。
- [ ] 无痕阅读开启时跳过新增与更新，已有历史保留。
- [ ] 历史页布局：左上「历史」页内标题胶囊；封面网格 + 书名；按 `openedAt` 倒序；不显示日期分组标题；空态。
- [ ] 按全新安装处理：不做历史回填，不写旧数据迁移。
- [ ] 页面级测试覆盖写入、去重、未入书架作品、无痕、点击与空态。
- [ ] `flutter analyze`、定向测试、Windows 构建通过。
