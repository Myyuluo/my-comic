**What to build:** 在「只看未读」左侧新增三态筛选 chip（全部 / 已下载 / 未下载），点击按序循环，并与「只看未读」AND 联动。

**Blocked by:** None（can start immediately）

**Status:** ready-for-agent

- [ ] 在章节列表头部、「只看未读」左侧新增 `FushiSelectableChip`；无 leading icon，纯文字，样式与「只看未读」同族。
- [ ] 三态循环顺序：全部 → 已下载 → 未下载 → 全部；标签显示当前状态。
- [ ] 状态是作品页会话内状态，不持久化，与「只看未读」一致。

- [ ] 与「只看未读」AND 联动；结果为空时显示现有空态。
- [ ] 章节计数徽章继续显示章节总数，不随任一筛选变化。
- [ ] 为筛选 chip 提供稳定 widget key。
- [ ] 页面级测试覆盖循环顺序、AND 联动、已下载判定、空态与计数不变。
