# 漫画阅读体验批量改进（manga-ux-batch）

Status: implemented
Date: 2026-11-09

## Problem Statement

漫画读者目前在阅读主链路上遇到 8 个问题：

1. 所有搜索框获得焦点后，输入第一个字符就会失去焦点，无法连续输入。
2. 本地图源的漫画阅读没有在线源那样的「正在阅读章节」高亮；读到章节最后一页后无法继续翻页，不会自动进入下一话。
3. 作品页「正在阅读」的章节 item 整行变色；读者希望只改变文字颜色，不改变 item 背景。
4. 作品页章节列表没有多选；读者希望长按进入多选，并通过底部批量栏批量标记已读、标记未读、删除已下载章节。
5. 作品页只有「只看未读」，缺少按下载状态筛选章节的能力。
6. 主导航没有历史页；读者无法集中查看读过的漫画、按书名搜索历史，或精准/全部删除历史记录。
7. 设置页没有清除缓存的入口，读者无法释放在线源封面与漫画图片占用的空间，也看不到缓存占用。
8. 设置页没有清除数据库的入口，读者无法清理未加入书架的作品记录、历史记录与阅读记录。

## Solution

- 统一修复所有搜索框的首字失焦：修复共享搜索组件与焦点/controller 所有权，让书架、本地图源、在线源浏览、Manga 全局搜索、扩展搜索与新增历史搜索都能连续输入。
- 让本地图源进入与在线源等价的章级阅读上下文：持久化当前章节与每章进度/已读状态；章节列表高亮当前章；读到章末自动进入下一话、章首继续往前进入上一话；同时修复多章续读、书架进度与未读角标、「标记此章及更早为已读」。
- 当前章节 item 只保留标题文字主色，移除整行背景、序号胶囊主色与标题加粗。
- 作品页章节列表支持长按多选；底部批量栏提供标记已读、标记未读、删除已下载章节；选中行使用参考图的深色底。
- 在「只看未读」左侧新增三态筛选「全部 / 已下载 / 未下载」，按序循环，并与「只看未读」AND 联动。
- 主导航在「下载」上方新增「历史」一级页面：以打开章节的阅读会话为准，每部 Manga 一条；支持搜索、单本删除、全部删除；无痕阅读不写入。
- 设置「存储与下载 → 数据存储位置」新增「清除缓存」：清理应用级图片、WebView/HTTP、解包临时缓存，显示当前占用，保留登录态与阅读数据。
- 同分组新增「清除数据库」：清理未入书架作品记录、全部 History 与孤儿阅读记录；保留 Library 作品及其阅读进度/已读状态、Download library、Local source 文件、设置与源。

## User Stories

### 搜索框焦点

1. 作为漫画读者，我希望在书架页头搜索输入第一个字符后仍保持焦点，以便连续输入而不必反复点击输入框。
2. 作为漫画读者，我希望在本地图源页搜索输入第一个字符后仍保持焦点，以便连续输入关键词。
3. 作为漫画读者，我希望在在线源浏览页与发现页搜索输入第一个字符后仍保持焦点，以便连续输入关键词。
4. 作为漫画读者，我希望在 Manga 全局搜索输入第一个字符后仍保持焦点，以便连续输入关键词。
5. 作为漫画读者，我希望在扩展商店与已装源搜索输入第一个字符后仍保持焦点，以便连续输入关键词。
6. 作为漫画读者，我希望在新增的历史页搜索输入第一个字符后仍保持焦点，以便连续输入书名。
7. 作为漫画读者，我希望中文输入法组字阶段的首键与英文直接输入都不丢焦点，以便任何输入方式都能正常工作。
8. 作为漫画读者，我希望清空、Esc 与收起搜索的现有行为保持不变，以便修复焦点不改变我的操作习惯。
9. 作为漫画读者，我希望各搜索框保持现有的查询时机（实时过滤或提交搜索），以便修复焦点不改变搜索体验。

### 本地源阅读

10. 作为漫画读者，我希望打开本地图源的章节后，该章节在章节列表中以文字主色标示为正在阅读，以便知道上次读到哪里。
11. 作为漫画读者，我希望重新打开本地图源作品时回到上次阅读的章节与页码，以便继续阅读。
12. 作为漫画读者，我希望读到最后一页继续往后翻时自动进入下一话第一页，以便连续阅读。
13. 作为漫画读者，我希望在第一页继续往前翻时进入上一话最后一页，以便回看上一话结尾。
14. 作为漫画读者，我希望最后一话或第一话的边界停在原地，以便不会误退出阅读器。
15. 作为漫画读者，我希望自动换章按本地章节的自然阅读顺序推进，以便阅读顺序正确。
16. 作为漫画读者，我希望本地章节列表的显示顺序保持现状，以便不因本次修复改变浏览习惯。
17. 作为漫画读者，我希望书架进度条对本地图源按章节计算，以便进度显示准确。
18. 作为漫画读者，我希望本地图源读完后书架未读角标正确减少，以便知道还剩多少章节没读。
19. 作为漫画读者，我希望「标记此章及更早为已读」对本地图源真实生效，以便批量整理本地源。
20. 作为漫画读者，我希望无痕阅读时仍保留续读位置，以便继续阅读不受影响。
21. 作为漫画读者，我希望在线源的阅读与换章行为完全不变，以便现有习惯不受影响。

### 当前章节样式

22. 作为漫画读者，我希望当前章节只改变章节标题文字颜色，以便弱化高亮、不抢视觉。
23. 作为漫画读者，我希望当前章节的背景与普通章节一致，以便章节列表更干净。
24. 作为漫画读者，我希望当前章节的序号胶囊恢复普通配色，以便只保留文字提示。
25. 作为漫画读者，我希望当前章节标题不再单独加粗，以便与普通章节样式统一。
26. 作为漫画读者，我希望读了一半的进度条继续显示，以便知道该章的阅读进度。

### 章节多选与批量操作

27. 作为漫画读者，我希望长按章节进入多选模式，以便快速批量操作多个章节。
28. 作为漫画读者，我希望在多选模式中单击切换选中，清空选择或点空白处退出，以便操作直观。
29. 作为漫画读者，我希望选中的章节行背景加深，以便清楚看到选中了哪些章节。
30. 作为漫画读者，我希望底部批量栏显示「已选 N 项 / 全选 / 反选」，以便批量选择章节。
31. 作为漫画读者，我希望全选/反选只作用于当前筛选后可见的章节，以便与筛选结果一致。
32. 作为漫画读者，我希望批量把选中的章节标记为已读，以便整理已读状态。
33. 作为漫画读者，我希望批量把选中的章节标记为未读，以便重新标记阅读状态。
34. 作为漫画读者，我希望批量删除选中的已下载章节，以便释放磁盘空间。
35. 作为漫画读者，我希望批量栏的已读、未读、删除图标符合参考图，以便一眼识别每个动作。
36. 作为漫画读者，我希望动作对当前选择不适用时置灰、混合选择只对适用子集执行，以便不会误操作。
37. 作为漫画读者，我希望标记已读/未读不弹确认，以便快速完成可逆操作。
38. 作为漫画读者，我希望删除已下载章节前有二次确认，以便避免误删下载文件。
39. 作为漫画读者，我希望本地图源的章节不能被批量删除，以便不误删我自己的磁盘文件。
40. 作为漫画读者，我希望多选在在线源与本地图源的章节列表中都可用，以便统一操作。

### 章节下载筛选

41. 作为漫画读者，我希望「只看未读」左侧新增一个三态筛选 chip，以便按下载状态筛选章节。
42. 作为漫画读者，我希望点击按「全部 → 已下载 → 未下载 → 全部」循环，以便用一个按钮完成切换。
43. 作为漫画读者，我希望「已下载」只统计下载完成的章节，以便筛选结果准确。
44. 作为漫画读者，我希望本地图源的章节恒为已下载，以便本地源行为符合直觉。
45. 作为漫画读者，我希望新筛选与「只看未读」是 AND 联动，以便组合筛选。
46. 作为漫画读者，我希望筛选无结果时看到空态，以便知道不是加载失败。
47. 作为漫画读者，我希望章节计数徽章仍显示总数，以便知道作品的总章节数。

### 历史

48. 作为漫画读者，我希望主导航「下载」上方新增「历史」，以便快速回到读过的漫画。
49. 作为漫画读者，我希望历史页以封面网格加书名展示读过的漫画，以便浏览。
50. 作为漫画读者，我希望历史按最近阅读时间倒序、每部漫画一条，以便快速找到最近读过的作品。
51. 作为漫画读者，我希望打开章节进入阅读器时记录或更新历史，以便历史反映真实阅读行为。
52. 作为漫画读者，我希望只打开作品详情页不产生历史，以便浏览作品不算阅读。
53. 作为漫画读者，我希望在线漫画只要实际开读过章节就出现在历史页（开读会先静默加入书架；之后仅移出书架也保留记录），以便不丢失阅读记录。
54. 作为漫画读者，我希望同一部漫画加入书架后历史里仍只有一条，并优先显示书架里的最新标题与封面，以便历史不重复、信息最新。
55. 作为漫画读者，我希望点击历史卡进入该漫画的作品页，以便继续阅读。
56. 作为漫画读者，我希望封面右上角是单本删除按钮，点击后立即删除并给出提示，以便精准清理单本记录。
57. 作为漫画读者，我希望右上角搜索按钮展开搜索框并实时按书名过滤历史，以便找到某部漫画。
58. 作为漫画读者，我希望右上角删除按钮在确认后清空全部历史，以便重置历史记录。
59. 作为漫画读者，我希望无痕阅读期间的新阅读不新增、不更新历史，以便无痕阅读不留痕迹。
60. 作为漫画读者，我希望删除历史不影响阅读进度、章节已读标记或书架状态，以便只清理历史。
61. 作为漫画读者，我希望删除整部作品时一并删除它的历史，以便不留下点开即失败的记录。
62. 作为漫画读者，我希望仅移出书架时保留历史，以便书架状态与阅读记录互不干扰。
63. 作为漫画读者，我希望历史为空时看到空态，以便知道还没有阅读记录。
64. 作为漫画读者，我希望作品来源不可用时历史卡仍然保留，点击后给出错误提示，以便不会崩溃或丢失记录。

65. 作为漫画读者，我希望「数据存储位置」分组新增「清除缓存」行并显示当前占用，以便知道能释放多少空间。

67. 作为漫画读者，我希望它能清除在线阅读的页流缓存与 CBZ 解包临时缓存，以便清理临时文件。
68. 作为漫画读者，我希望它能清除远端封面与缩略图缓存，以便全面清理应用缓存。
69. 作为漫画读者，我希望它能清除内存中的图片缓存，以便立即释放内存。
70. 作为漫画读者，我希望它能清除 WebView/HTTP 响应缓存但不影响图源登录态，以便不用重新登录。

### 清除数据库

73. 作为漫画读者，我希望「数据存储位置」分组新增「清除数据库」行并以破坏性样式呈现，以便明确这是不可逆操作。

76. 作为漫画读者，我希望它删除无法对应任何作品的孤儿阅读记录，以便清理无归属数据。
77. 作为漫画读者，我希望它保留书架作品及其阅读进度、已读标记与完成标记，以便不破坏书架阅读状态。
78. 作为漫画读者，我希望它保留 Download library 文件、Local source 文件、设置、源与扩展、搜索历史，以便只清理数据库记录。

80. 作为漫画读者，我希望清除数据库不需要重启，以便清理后立即继续使用。

## Implementation Decisions

### 搜索框焦点

- 统一走共享搜索组件（搜索形态层、行为层、页头可展开搜索层与 IME/防抖驱动）；仍直接使用形态层的页面迁回行为层，不做逐页特判。
- controller 与 FocusNode 由页面 State 持有；查询变化不得改变搜索框的 key、祖先结构或浮动 chrome 槽位登记。
- 组字阶段不把 composing text 当成最终查询；保留各页现有查询时机与 Esc、清空、收起行为。
- 历史页搜索复用修复后的页头搜索路径，不新增第二套搜索实现。
- 不改变搜索框的尺寸、颜色、图标与布局。

### 本地源章级阅读上下文

- `LocalSourceMetadata`（`EpubBooks.sourceMetadata` 的 JSON）增加可选 `currentChapterKey`；章节身份使用章节相对路径（文件夹章节目录名或 `.cbz` 文件名）。
- 复用 `manga_chapter_states` 存本地源的章级 `lastPage`、`lastFraction`、`pageCount`、`readAt`、`updatedAt`，`chapterKey` 与 `currentChapterKey` 使用同一相对路径。
- 不新增表或列，不做数据库迁移；重命名章节文件会丢失该章状态。
- 阅读器的本地源路径填充与在线源等价的章级上下文（书目、章节列表、当前 chapterKey），使当前章高亮、章级进度写入、自动换章、章内续读复用在线源同一套逻辑。
- 打开与切换章节时更新 `currentChapterKey`；首页/历史等直接开书用 `currentChapterKey` 解析当前章与页码。
- 本地章节按扫描时的自然顺序（第 1 话→第 N 话）作为阅读顺序；下一话 = 索引 +1，上一话 = 索引 −1。在线源保持「新→旧」顺序与下一话 = 索引 −1 的现有逻辑，不得混用方向。
- 读到最后一页继续后翻进入下一话第一页；在第一页继续前翻进入上一话最后一页；最后一话/第一话边界停在原地并给出与在线源一致的边界提示。webtoon/连续滚动模式保持现有行为，不在本次扩展自动换章。
- 书架进度对本地源改为按章节计算；章节总数从 `chaptersJson` 的章节数推导，不使用 `EpubBooks.chapterCount` 的总页数语义。
- 章末自动写入 `readAt`（受无痕策略约束），书架未读角标因此对本地源生效；修复「标记此章及更早为已读」对本地源的空操作。
- 无痕阅读保留章级位置、冻结 `reader_positions.updatedAt`、不自动写 `readAt` 与书级 `completedAt`；手动标记已读/未读不受影响。
- 本地章节列表的显示顺序保持现状，不与在线源翻转。

### 当前章节样式

- 当前章节只保留标题文字为 `primary` 色。
- 移除当前章节的整行背景高亮、序号胶囊主色底与反色字、标题 emphasized 字重。
- 读了一半的进度条、已读对勾、下载状态图标与副标题保持不变。
- 多选选中态背景使用 `primaryContainer`（与参考图的浅蓝一致）；当前章节背景移除后两者不再冲突。

### 章节多选与批量操作

- 复用现有选择状态机、底部批量栏与弹簧容器、长按/点击手势层、行级 selected 标记；选择状态放在作品页级，不放在会被下载状态重建的行子树内。
- 长按任意章节进入多选；进入后单击切换选中；清空选择或点空白处退出；桌面端不额外提供右键/Ctrl+点击入口。
- 选中行背景使用 `primaryContainer`，前景 `onPrimaryContainer`；保留已读对勾与下载状态。
- 批量栏左侧为「已选 N 项 / 全选 / 反选」，右侧三个动作按钮：已读用圆形空心对勾、未读用圆形实心对勾、删除用垃圾桶。
- 全选/反选只作用于当前筛选后可见的章节；筛选变化时保留仍可见项的选择，批量动作只作用于当前可见的选中项。
- 批量标记已读/未读写章节级 `readAt`，与单章菜单语义一致，不改书级 `completedAt`；不弹确认。
- 全部选中项已读时「标记为已读」置灰；全部未读时「标记为未读」置灰；混合选择只对适用子集执行。
- 批量删除只对应用管理的在线下载生效，且只删下载状态为「已完成」的章节；排队中/下载中/文件缺失不参与；删除前二次确认；已读标记与阅读进度保留。
- 本地图源章节的磁盘文件属于用户文件，垃圾桶动作对本地源始终不可用。
- 没有选中项时批量栏隐藏；批量栏不遮挡最后一个章节行。

### 章节下载筛选

- 在章节列表头部、「只看未读」左侧新增一个 `FushiSelectableChip`；无 leading icon，纯文字，样式与「只看未读」同族。
- 三态循环顺序：全部 → 已下载 → 未下载 → 全部；标签显示当前状态。
- 状态是作品页会话内状态，不持久化，与「只看未读」一致。
- 「已下载」只统计下载状态为已完成的章节；排队中、下载中、暂停、文件缺失都算未下载；本地图源章节恒为已下载。
- 与「只看未读」AND 联动；结果为空时显示现有空态。
- 章节计数徽章继续显示章节总数，不随任一筛选变化。
- 为筛选 chip 提供稳定 widget key，便于页面级测试。

### 历史

- 新增 `HomeTab` 值「历史」，导航可见列表固定插在「浏览」之后、「下载」之前；补齐图标/标签、页面挂载、外壳标题与控制通道页签名；图标沿用现有历史/时钟图标。
- 历史页以 `media_open_history` 为唯一数据源；不读取 `reader_positions.updatedAt` 作为历史页来源（见 ADR 0018）。
- 打开章节进入阅读器时写入/更新历史，包括作品页开章、首页继续阅读直接开书、阅读器内切章；只打开作品详情页不写。每部 Manga 一条，重复阅读更新 `openedAt` 并置顶。
- 历史条目身份是「Source + 作品 id」；本地图源使用本地伪源 + 相对路径。同一作品从未入书架变为已加入 Library 后仍是同一条，渲染优先使用 Library 的最新标题与封面。
- 在线作品开读时会先静默加入 Library，进度、已读与历史都按 Library 条目落库；历史身份仍是「Source + 作品 id」，作品之后仅移出 Library（保留文件）时历史保留。`snapshotJson` 保存 source id、作品 id、URL、标题、封面；点击时按来源身份打开来源作品页并拉取详情。
- 无痕阅读开启时跳过新增与更新，已有历史保留。
- 历史页布局：左上「历史」页内标题胶囊；右上只有「搜索」「删除」两个按钮；封面网格 + 书名；按 `openedAt` 倒序；不显示日期分组标题。
- 封面右上角原未读角标位置改为单本删除按钮；点击立即删除并 toast，不逐条确认。
- 搜索按钮展开页内搜索行，复用修复后的搜索组件，实时按书名过滤；清空或收起恢复完整列表。
- 全部删除弹二次确认后清空全部历史。
- 删除历史只删历史记录，不清除 Reading progress、章节 `readAt`、书级完成标记或书架状态。
- 删除整部作品（含文件）时级联删除历史；仅移出书架保留历史。
- 来源不可用时点击历史卡给出错误提示并保留条目；历史为空时显示空态。
- 按全新安装处理：不做历史回填，不写旧数据迁移。

### 清除缓存

- 在「数据存储位置」分组现有两行之后追加「清除缓存」动作行，副标题显示当前磁盘缓存占用；行顺序在「清除数据库」之前。
- 清理范围：Mihon 封面缓存、在线页流缓存、CBZ 解包缓存、远端封面缓存、缩略图缓存、图片缓存管理器的磁盘缓存、Flutter 内存 ImageCache、默认与漫画 WebView profile 的 HTTP 缓存。
- 页流与解包缓存只清不在活跃阅读会话中的目录；复用现有活跃目录保护。
- WebView/HTTP 缓存通过 CDP `Network.clearBrowserCache` 清理；没有可见 WebView 时临时创建 headless WebView 加载 `about:blank` 执行后销毁。
- 永不整目录删除 WebView2 数据目录；只清 HTTP cache 层，保留 cookies / localStorage / IndexedDB / Preferences。
- 只清 Mihon 的封面缓存子目录，不删除整个 Mihon 数据目录（其中有登录态与扩展数据）。
- 不删除 Download library、Local source 目录与封面文件、数据库、History 或 Reading progress。
- 某类 WebView 缓存无法安全清理时跳过并在结果中体现部分成功；单文件删除失败时继续清理其余项。
- 大小统计只扫描上述显式缓存目录，不扫描整个系统临时目录；内存缓存不计入显示值。
- 确认框显示当前占用；执行时复用「重建下载索引」的进度框模式；完成后 toast 显示释放量；不需要重启。

### 清除数据库

- 在「数据存储位置」分组末尾、「清除缓存」之后追加「清除数据库」动作行，使用 destructive 红色样式。
- 删除全部 `media_open_history` 行（含未入书架作品的 snapshot 行）。
- 删除不在 Library 中的作品记录（`EpubBooks` 行）及其级联的章级状态、阅读位置、阅读覆盖、下载任务、章节容器映射；只删记录、不删磁盘文件。
- 删除无法对应任何作品的 `reader_positions` / `manga_chapter_states` 孤儿行。
- 保留 Library 作品及其 Reading progress、章节 `readAt`、书级完成标记。
- 保留 Download library 文件与索引、Local source 目录与文件、设置、源、扩展、搜索历史、Tracking 数据。
- 确认框显示将删除的数量（作品 X 部 / 历史 Y 条 / 阅读记录 Z 条）；执行时用进度框；删除在一个事务中完成；完成后 toast 结果；不需要重启。
- 不等同于恢复出厂设置：不删设置/源/扩展，不删搜索历史，不删下载文件。

## Testing Decisions

- 好测试只断言用户可见的外部行为与数据结果，不测试私有方法、widget 结构或实现细节。页面级测试挂载真实页面，使用真实的 37 表数据库与真实偏好库；在线 Source 与下载服务使用可控 fake；缓存测试使用临时目录。
- **测试 seam：只使用一个现有 seam**——仓库已有的页面级 widget/集成测试 seam（真实数据库 + 可控 Source/下载服务 + 真实偏好库）。不新增更低层或更高层的 seam。
- 覆盖模块：
  - 搜索焦点：每个可达搜索框模拟输入第一个字符（含 IME 组字与 ASCII），断言焦点仍在输入框；保持现有书架搜索回归测试通过。prior art：`manga_library_tags_in_chrome_test`。
  - 本地源阅读：当前章高亮、章末自动下一话、章首自动上一话、边界停留、多章续读、书架进度与未读角标、标记此章及更早、无痕策略。prior art：现有 reader 测试、`manga_incognito_reading_test`、章节列表测试。
  - 当前章样式：当前行无背景、标题主色、读了一半进度条仍在；普通行不变。
  - 多选与批量：长按进入、单击切换、全选/反选可见项、批量已读/未读、删除已下载章节（含本地源禁用）、置灰规则与确认框。
  - 下载筛选：三态循环、与只看未读 AND、已下载判定、空态、计数不变。
  - 历史页：打开章节写一条、详情页不写、每部一条、未入书架作品、加入书架去重、无痕不写、搜索、单本删除、全部删除、删除历史不影响进度、删除作品级联、移出书架保留。
  - 清除缓存：临时目录大小统计、清理范围、登录态/下载/本地文件保留、活跃会话跳过、部分成功提示。
  - 清除数据库：删除对象与保留对象、数量统计、事务行为、无需重启。
- 回归验证：`flutter analyze`、定向 widget/unit 测试、Windows 构建；手动核对八个入口的真实交互（尤其搜索框 IME 首字、本地源换章、历史页与设置页清理）。

## Out of Scope

- 重新设计搜索框或引入任何新视觉语言；本次只修焦点行为。
- 改变在线源的章节顺序、阅读行为或换章方向。
- 改变「只看未读」的现有交互或计数语义。
- 历史回填、旧数据迁移或兼容旧历史行（按全新安装处理）。
- 删除搜索历史。
- 清除数据库时删除设置、源、扩展、下载文件或本地图源文件。
- 通过删除 WebView2 数据目录来清缓存；清理图源登录态。
- TTS 缓存、全局查词 WebView profile 等非漫画链路缓存。
- 数据库 schema 变更或表迁移（本地源仅在 `sourceMetadata` JSON 增加可选字段）。
- 富任务浏览器、其它一级导航项或非漫画模块的改动。
- 通过右键/Ctrl+点击进入多选。
- 在连续滚动模式下扩展自动换章。
