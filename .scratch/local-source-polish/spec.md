# 本地图源打磨：local 目录、封面、选择与过滤（local-source-polish）

Status: implemented
Date: 2026-11-08

## Problem Statement

本地图源已经能扫描 `localcomic` 并逐部加入书架，但日常使用仍有明显摩擦：

- 设置里的 CBZ 开关副标题没有说清关闭后的结果。
- 本地漫画根目录叫 `localcomic`，与产品里统一使用的「本地图源 / local」命名不一致。
- 下载库的源目录只有源名，没有语言；同名源（例如两个中文源）在资源管理器里难以区分。
- 本地图源扫描出来的漫画没有封面：网格只认作品根目录的 `cover.jpg/jpeg/png`，CBZ 作品在加入书架后也没有封面。
- 漫画页右上角的「排序与筛选」第二次点击会关了又开；「选择」弹出的底部批量栏会闪两次。
- 本地图源页没有批量选择与状态过滤，本地漫画一多，逐部加入/移出书架非常低效。

## Solution

- 修改 CBZ 开关的副标题文案。
- 本地源根目录永久更名为 `local`，不做旧数据迁移。
- 新下载的源目录命名为 `source (LANG)`，语言大写；已有目录不重命名。
- 扫描时在缺失封面的作品根目录生成 `cover.jpg`（第一页、600px 宽 JPEG），后台逐个补齐，并同步已入架作品的 `coverPath`。
- 修复漫画页「排序与筛选」的关闭/重开问题与批量栏的二次入场闪烁。
- 为本地图源做独立页面：标题右侧「全部 / 未入架 / 已入架」页签、右上「选择」、底部批量栏、鼠标长按进入选择，支持批量加入/移出书架。

## User Stories

1. 作为一个漫画读者，我希望 CBZ 开关下面写清楚「关闭后，下载的漫画将以文件夹+图片形式保存」，以便我知道关闭后的结果。
2. 作为一个漫画读者，我希望本地漫画根目录叫 `local`，以便和产品里的「本地图源」命名一致。
3. 作为一个漫画读者，我希望升级后旧 `localcomic` 不再被扫描，以便应用只使用新的 `local` 目录。
4. 作为一个漫画读者，我希望 `local` 目录在首次启动 / 切换存储位置时被创建，以便我直接把漫画放进去。
5. 作为一个漫画读者，我希望本地图源行显示 `local` 的实际路径，以便我知道文件该放哪里。
6. 作为一个漫画读者，我希望新下载的源目录命名为 `六漫画 (ZH)` 这种形式，以便在资源管理器里区分同名但语言不同的源。
7. 作为一个漫画读者，我希望源语言为空、`all` 或 `multi` 时不写语言后缀，以便目录名不出现无意义的 `(ALL)`。
8. 作为一个漫画读者，我希望同一源的同名同语言冲突仍自动加短后缀，以便不会互相覆盖。
9. 作为一个漫画读者，我希望已有下载目录保持原名、不被批量重命名，以便升级不破坏现有文件。
10. 作为一个漫画读者，我希望 `pages.json` 里继续保存裸源名，以便元数据不受目录命名影响。
11. 作为一个漫画读者，我希望扫描到的本地漫画都有封面，以便网格不再是一片灰色占位。
12. 作为一个漫画读者，我希望加入书架后的本地漫画也有封面，包括 CBZ 作品，以便书架和作品页都能正常显示。
13. 作为一个漫画读者，我希望封面从第一页生成，以便不需要手动准备图片。
14. 作为一个漫画读者，我希望已有 `cover.jpg/jpeg/png` 时不被覆盖，以便保留我自己的封面。
15. 作为一个漫画读者，我希望封面逐部在后台生成、网格先显示列表，以便本地漫画很多时不用一直等。
16. 作为一个漫画读者，我希望封面生成失败或第一页损坏时保留占位、下次再试，以便不会卡住或写出坏图。
17. 作为一个漫画读者，我希望漫画页「排序与筛选」点一次展开、再点收起，以便菜单行为符合直觉。
18. 作为一个漫画读者，我希望漫画页「选择」的底部批量栏只出现一次，以便没有闪烁和重复入场。
19. 作为一个漫画读者，我希望本地图源页右上角有「选择」按钮，图标与漫画页一致，以便进入多选。
20. 作为一个漫画读者，我希望进入选择模式后「选择」变成 X，点 X 或 ESC 退出，以便明确退出方式。
21. 作为一个漫画读者，我希望本地图源页底部出现与漫画页同款的批量栏，以便批量操作。
22. 作为一个漫画读者，我希望批量栏显示「已选 N 项 / 全选 / 反选」，以便快速选择。
23. 作为一个漫画读者，我希望批量加入书架使用漫画详情页的加入书架图标，以便识别动作。
24. 作为一个漫画读者，我希望批量移出书架使用图三的垃圾桶图标，以便识别动作。
25. 作为一个漫画读者，我希望加入书架只作用于选中且未入架的作品，以便不会重复登记。
26. 作为一个漫画读者，我希望移出书架只作用于选中且已入架的作品，以便不会误操作未入架作品。

30. 作为一个漫画读者，我希望批量操作成功后自动退出选择并刷新列表，以便马上看到结果。
31. 作为一个漫画读者，我希望批量操作有成功/失败数量的提示，以便知道执行结果。
32. 作为一个漫画读者，我希望本地图源页标题右边有「全部 / 未入架 / 已入架」页签，以便按书架状态筛选。
33. 作为一个漫画读者，我希望「未入架」只显示未加入书架的作品（包括已移出书架的），以便快速挑选要加入的作品。
34. 作为一个漫画读者，我希望「已入架」只显示已加入书架的作品，以便管理已有作品。
35. 作为一个漫画读者，我希望过滤与搜索叠加，以便先按状态筛再按标题找。
36. 作为一个漫画读者，我希望切换过滤页签时退出选择模式，以便不会在隐藏项上继续操作。
37. 作为一个漫画读者，我希望在本地图源卡片上鼠标长按进入选择并选中该作品，以便快速多选。
38. 作为一个漫画读者，我希望选择模式下单击或长按切换选中，普通模式单击打开作品页，以便交互与漫画页一致。
39. 作为一个漫画读者，我希望本地图源页过滤后没有结果时显示现有空态/无结果提示，以便知道是过滤而不是加载失败。
40. 作为一个漫画读者，我希望这些改动继续使用现有组件、主题与布局，以便界面保持熟悉。

## Implementation Decisions

### 文案与本地源根目录

- `保存为CBZ压缩包` 的副标题改为「关闭后，下载的漫画将以文件夹+图片形式保存。」，所有 locale 同步（base 英文、简中、繁中提供准确文案，其余用英文基线）。
- 本地源根目录的文件夹名常量从 `localcomic` 改为 `local`；Content root 创建、Content root 切换、静态路径 getter 都随之创建 `local`。
- **不做迁移**：旧 `localcomic` 不扫描、不搬移、不删除；旧登记行会变成 Missing，这是接受的开发阶段代价。
- 内部 Dart API 名（`localComicRoot` 等）保持不变，只改常量值、注释与文档，避免全仓符号改名。
- 用户可见字符串、GLOSSARY、ADR、安装器 guard、存储用量分类同步改为 `local`；旧目录归入存储用量的「其他」。
- 安装器 guard 的禁用项必须写成路径限定的 `{userdocs}\MyComic\local`，不能裸写 `local`（会误匹配 `localappdata`）。

### 下载源目录命名

- 新下载的源目录名 = 源显示名 + 空格 + `(LANG)`，语言取 Source 的 language 原值并大写，保留子标签（`zh-Hans` → `ZH-HANS`）。
- 空、`all`、`multi` 视为无语言，只写源名，不写括号。
- 源目录名的 Windows 净化、长度预算与截断沿用现有规则；同名同语言冲突沿用现有短哈希后缀。
- 只影响新下载；已有源目录按源身份复用，不重命名（与 ADR 0012「目录名不是身份」一致）。
- `pages.json.source.name` 保持裸源名；语言只体现在目录名。
- 语言来源：Mihon 源行（`manga_online_sources.language`）或运行时提供；没有语言能力的运行时（互联、旧 Aidoku）不写后缀。

### 本地图源封面

- 扫描作品时，若作品根目录没有 `cover.jpg/jpeg/png`，生成 `cover.jpg`：取第一部章节的第一页（自然顺序）；CBZ 作品取第一个压缩包 `pages.json` 排序后的第一页（无 manifest 时按图片名自然排序）。
- 封面缩放到宽 600px（小于 600 不放大）、JPEG 质量 85；通过现有原子封面写入与可解码校验路径写入；绝不覆盖已有封面。
- **后台逐个生成**：本地图源页先显示扫描结果与占位，封面生成完成后更新对应卡片；生成失败的页跳过，下次进入重试；不写坏图。
- 已登记作品如果 `coverPath` 为空（典型 CBZ）或指向旧第一页，生成后把 `coverPath` 更新为 `cover.jpg`，使书架与作品页立即显示。
- 封面文件写在用户 `local` 文件夹内，是可见文件、不是隐藏元数据；ADR 0013 需补修订说明，明确扫描允许写缺失的 `cover.jpg`，但仍不写隐藏 ID、不覆盖、不复制/移动页文件。
- 扫描的只读约束从「完全不写」调整为「只允许补写缺失的 `cover.jpg`」。

### 漫画页菜单与批量栏

- 「排序与筛选」：修复第二次点击关了又开的问题。根因是触发按钮在菜单 tap region 外，按下被当外部点击关闭、抬起又重新打开；修复后同一按钮点击一次展开、再点收起，点外部或 ESC 仍关闭，菜单内容与选项行为不变。
- 「选择」批量栏：修复批量栏出现两次的问题。根因是外层 reveal 动画结束后重建了 `BatchActionBar`，而它自带一次入场 tween；修复后批量栏只播放一次入场，选择模式状态与批量栏内容不变。
- 两项修复不改变漫画页的其它布局与交互。

### 本地图源独立页面

- 本地图源使用独立页面，不复用在线源壳；页面保留现有扫描、搜索、封面网格、空态与错误态。
- 头部布局：返回键 + 「本地图源」浮动标题胶囊 + 标题右侧「全部 / 未入架 / 已入架」页签（沿用「浏览 / 图源 / 发现」同款分段页签样式，选中项胶囊高亮）+ 右侧「选择」浮动按钮；搜索框在标题行下方。
- 选择模式：点「选择」进入，按钮变 X；点 X 或 ESC 退出；底部出现 `BatchActionBar`。
- 批量栏内容：已选 N 项 / 全选 / 反选 + 「加入书架」（`FushiIcons.libraryAdd`）+ 「移出书架」（图三垃圾桶 `Icons.delete_outline`）；两个动作始终显示，无适用项时置灰。
- 选择语义：加入书架作用于选中且未入架的作品；移出书架作用于选中且已入架的作品；移出只删除书架条目并写 tombstone，绝不删除 `local` 文件；已移出书架的 tombstone 作品算未入架，显式加入时会重新登记。
- 全选/反选只作用于当前页签 + 搜索后可见的列表；切换过滤页签时退出选择模式并清空选择。
- 鼠标长按卡片进入选择并选中该作品；选择模式下单击/长按切换选中；普通模式单击打开作品页。该长按行为只加在本地图源页，漫画书架页维持现状。
- 批量操作成功后退出选择模式并刷新状态；用 toast 报告成功/失败数量，不做部分保留选择。
- 状态判定：「已入架」= 按作品目录路径派生的本地作品身份在 `EpubBooks` 中存在登记行；tombstone 作品算未入架，仍在网格显示。
- 过滤与搜索叠加；过滤无结果时复用现有空态/无结果态，不新增另一套文案。
- 所有新 UI 复用现有组件、图标、主题与布局（ADR 0008），不重绘、不引入新视觉风格。

### 数据与接口

- 本地源根目录仍通过 `AppPaths` 注入；扫描/登记/阅读/重建都跟随注入的 root，不硬编码文件夹名。
- 封面生成使用现有图片解码/缩放/编码与原子写封面能力；不新增依赖。
- 本地图源的「已入架」状态通过现有 `EpubBooks` 查询与本地作品身份计算；不新增持久化列。
- 批量加入复用单作品登记入口；批量移出复用现有本地作品移出书架路径（写 tombstone、保留文件）。
- 下载源目录名的语言拼接在 app 层完成（语言来自 Mihon 源行），engine 只接收最终显示名并继续负责净化/截断；`pages.json` 仍写裸源名。

## Testing Decisions

### 好测试的标准

- 只测试外部行为：`local` 目录是否创建、`localcomic` 是否被忽略、下载目录名、`cover.jpg` 是否存在/是否覆盖、`EpubBooks.coverPath` 是否更新、页面显示哪些作品、批量操作后书架行与 tombstone 状态、菜单与批量栏出现次数。
- 不测试私有函数；不 mock 文件系统；使用真实临时目录与真实 SQLite。
- 动画修复用 widget 测试断言「批次栏只出现一次 / 第二次点击菜单关闭」，不依赖动画实现细节。

### Seams

- **主 seam（不新增注入点）**：现有真实临时目录测试根（`FUSHI_TEST_ROOT` / 测试目录）+ `AppPaths.resolve()` + 真实数据库 + 公共 service（Local source scan/register、封面生成、下载目录解析、Rebuild）。覆盖文件、DB 与服务的端到端行为。
- **UI seam（复用现有）**：现有漫画书架页 widget 测试（选择/批量栏/排序菜单）、新本地图源页 widget 测试（复用现有 AppModel/DB harness）、设置页与 i18n guard 测试。
- 不新增测试框架；如本地图源页需要注入扫描/封面生成，优先使用现有 service seam。

### Prior art

- 本地源：`local_source_scan_test`、`local_source_library_test`、`local_source_drop_test`、`local_source_reader_test`、`local_source_browse_page_test`、`local_source_entry_row_test`、`local_source_shelf_remove_test`。
- 选择与批量栏：`media_selection_controller_test`、`selection_gestures_test`、`reader_shelf_batch_actions_manga_schema_test`、`reader_remote_multiselect_test`、`manga_library_tags_in_chrome_test`、`reader_shelf_read_status_filter_persist_test`。
- 下载目录命名：`download_library_storage_test`、`online_manga_library_test`、`manga_download_service_test`、`download_library_index_test`。

### 场景覆盖

- 文案：zh-CN/zh-HK 副标题为指定文本，i18n 排序/完整性 guard 通过。
- `local` 根：默认与自定义 Content root 都创建 `local`；`localcomic` 不再被扫描；本地图源行副标题显示 `local` 路径；旧 `localcomic` 目录不删除。
- 源目录：`Name (ZH)`、`Name (ZH-HANS)`、空/`all`/`multi` 无后缀、同名同语言短哈希、长度截断、已有目录不重命名、`pages.json` 裸名。
- 封面：文件夹作品无封面 → 生成 `cover.jpg`；CBZ 作品 → 从第一页生成；已有 `cover.jpg/png` 不覆盖；坏页跳过且留占位；已入架作品 `coverPath` 更新；后台补齐不阻塞网格。
- 漫画页：排序菜单第二次点击关闭；选择批量栏只出现一次；其它行为不变。
- 本地图源页：标题右侧三个页签默认全部、过滤+搜索叠加、切换页签退出选择；选择/全选/反选/长按；批量加入未入架、批量移出已入架、混合选择、按钮置灰、移出不删文件；批量后退出并刷新；tombstone 作品算未入架且可重新加入；过滤无结果空态。
- 回归：在线源页、漫画书架页、设置页、下载页不受影响。

## Out of Scope

- 旧 `localcomic` 的迁移、重命名或自动搬移；旧数据兼容。
- 已有下载源目录的重命名或批量迁移。
- 缓存式封面（本次选择写入 `local` 文件夹）。
- 本地图源之外的封面生成（在线源、下载库）。
- `pages.json` 增加语言字段。
- 批量下载、批量标签、批量重置进度、批量删除等其它批量动作。
- 删除 `local` 文件（移出书架只删条目）。
- 自动文件监视。
- iOS 特例；本项目不做 iOS。
- UI 重设计、主题/美术或布局变更。
- 全量测试套件中与本次无关的既有红灯（如其他 locale 缺 storage-layout i18n key、settings renderer 旧断言、BUG-3101）。

- 建议实现顺序：P1 文案 + `local` 根 + 源目录命名；P2 封面生成与 `coverPath` 同步；P3 漫画页菜单/批量栏修复；P4 本地图源独立页（页签、选择、批量栏、长按）；P5 测试与文档收尾。
- 主要风险：写入用户 `local` 文件夹的封面策略需要 ADR 明确；扫描 + 后台封面生成在大库下的性能；「已入架」状态查询与批量操作后的刷新；长按与单击/滚动手势冲突；共享漫画页选择/菜单修复不能回归书架页。
