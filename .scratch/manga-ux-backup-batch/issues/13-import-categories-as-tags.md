# 13: 导入：Mihon 分类恢复为标签

**What to build:** 导入 Mihon 备份时，把分类按名称创建或合并为 Tag、按分类 order 设置排序并分配给对应作品；不再写入隐藏合集；已有隐藏合集保持原样、不迁移。

**Blocked by:** None（can start immediately）

**Status:** ready-for-agent

- [ ] 导入 Mihon 备份后，每个分类按名称创建为 Tag；已存在同名 Tag 时复用，不重复创建。
- [ ] Tag 顺序来自分类 order；新 Tag 使用默认颜色。
- [ ] 每部作品的分类 order 转换为对应 Tag 分配；多分类写入多个 Tag。
- [ ] 导入不再创建新的隐藏合集或合集成员；已有的隐藏合集保持原样、不迁移。
- [ ] 有分类的作品导入后出现在对应标签页签，不出现在「书架」页签（现有规则）。
- [ ] 重复导入同一备份时 Tag 分配幂等，不重复挂载。
- [ ] 备份导入 seam 测试覆盖新建、复用、排序、多分类、不写合集与幂等。
