# 04: 加入书架前选择标签：核心选择器与在线作品页

**What to build:** 标签选择器增加“延迟写入”模式，只返回选择结果、不立即写数据库；在线 Manga 作品页点「加入书架」时，用户已有 Tag 则先弹选择器，没有 Tag 则直接加入；支持多选、零选、完成入架与关闭取消。

**Blocked by:** None（can start immediately）

**Status:** ready-for-agent

- [ ] 用户已有至少一个 Tag 时，在线 Manga 作品页点「加入书架」先显示标签选择弹窗，标题为「标签」，副标题显示 1 个条目。
- [ ] 用户没有任何 Tag 时，直接加入 Library，不显示弹窗。
- [ ] 弹窗复用现有标签选择器的搜索、全部标签、新建标签与完成按钮。
- [ ] 可以多选 Tag，也可以一个都不选；零选时加入后为未打标签，作品出现在「书架」页签。
- [ ] 点「完成」才创建 Library 条目并写入所选 Tag；点弹窗外部、按 Esc 或关闭弹窗则取消加入，不创建条目、不写 Tag。
- [ ] 选择阶段不写数据库；加入失败时不留 Tag 分配。
- [ ] 加入并打 Tag 后，作品只出现在对应标签页签，不出现在「书架」页签（现有规则不变）。
- [ ] 页面级测试覆盖有 Tag 与无 Tag、多选与零选、完成与取消、加入失败不留标签。
