# 02: 书架批量与单卡菜单接入统一移出弹窗

**What to build:** 书架选择模式的批量删除与单卡长按菜单的删除都使用 01 的统一弹窗；批量操作补上在线 Manga 已下载章节的文件删除；逐作品独立处理并报告部分失败；继续提示被筛选隐藏的选中项。

**Blocked by:** 01（统一移出书架弹窗与单本删除语义）

**Status:** ready-for-agent

- [ ] 书架选择模式点批量删除、单卡长按菜单点删除，都显示与 01 相同的弹窗与文案；批量文案包含选中的作品数量。
- [ ] 批量弹窗的两个勾选项默认不勾选；统计数据删除应用于所有选中作品；本地文件删除同时覆盖在线已下载章节与本地原作。
- [ ] 混合选择在线与本地 Manga 时，文件删除按作品类型分别处理；本地原作仅在勾选时删除。
- [ ] 逐作品独立处理：部分文件删除失败时，失败作品保留在 Library，成功作品移出；结果报告成功与失败数量。
- [ ] 被当前筛选隐藏的选中项继续显示现有提示，且不参与本次删除。
- [ ] 在线 Manga 的排队中或下载中任务在移出前停止并取消。
- [ ] 批量移出后 History 保留；Reading progress、Chapter 已读标记与 Tag 分配被删除。
- [ ] 页面级测试覆盖批量与单卡、混合选择、部分失败与隐藏选中项提示。
