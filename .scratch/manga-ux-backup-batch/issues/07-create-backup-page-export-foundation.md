# 07: 创建备份页与导出基础（书架作品、章节）

**What to build:** 新建「创建备份」独立页，按参考布局提供「书架」「设置」两组卡片与底部创建按钮；先交付「书架中的作品」「章节」两个勾选项；保存对话框、默认文件名、进度与结果提示；实现 gzip + protobuf 写入器与标准偏好值类型；「创建备份」设置行更名并启用，生成 Mihon 可导入的 `.tachibk`。

**Blocked by:** None（can start immediately）

**Status:** ready-for-agent

- [ ] 设置中的「创建备份」行标题与副标题更新为「创建备份」「将书架数据导出为.tachibk文件。」，点击进入独立创建备份页。
- [ ] 创建备份页按参考图分「书架」「设置」两组卡片，底部有「创建」按钮；首批提供「书架中的作品」「章节」勾选项，默认勾选。
- [ ] 取消「书架中的作品」时「章节」置灰；没有可导出项时「创建」置灰。
- [ ] 点「创建」弹出保存对话框，默认目录为 Backup directory，默认文件名 `my-comic_YYYY-MM-DD_HH-mm.tachibk`；取消保存不写文件。
- [ ] 导出文件为 gzip + protobuf，字段号对齐 Mihon v0.21.3；书架作品包含 Source ID、作品 URL、标题、作者、封面、加入时间与 favorite=true；章节包含 URL、名称、read、lastPageRead、日期与章节号。
- [ ] 偏好值只使用六种标准类型与标准类型名，不使用自定义类型。
- [ ] 写入临时文件，成功后移动到目标路径；失败时删除临时文件并提示；目录中不残留半成品。
- [ ] 创建过程显示进度，成功后提示文件路径。
- [ ] 导出的文件可被现有导入器解析并恢复 Library 与章节；用 Mihon v0.21.3 手动导入可正常恢复书架。
- [ ] 备份 fixture/parser/import-service seam 测试覆盖字段、gzip、文件命名、取消保存与失败清理。
