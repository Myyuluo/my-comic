# 05: 本地作品页与本地图源批量加入时选择标签

**What to build:** 本地 Manga 作品页「加入书架」与 Local source 页批量「加入书架」接入 04 的统一标签选择器；批量只弹一次并把同一组 Tag 应用到本批新加入作品；重新加入已移出书架的本地作品同样生效；静默加入保持无弹窗、未打标签。

**Blocked by:** 04（加入书架前选择标签：核心选择器与在线作品页）

**Status:** ready-for-agent

- [ ] 已有 Tag 时，本地 Manga 作品页加入书架先弹标签选择；零 Tag 时直接加入。
- [ ] Local source 页批量加入在已有 Tag 时只弹一次，副标题显示本批要加入的作品数量。
- [ ] 批量所选 Tag 应用到本批所有新加入作品；已在 Library 的作品不重新加入、不应用 Tag。
- [ ] 重新加入已移出书架的本地作品时同样弹选择器并可打 Tag。
- [ ] 关闭弹窗取消整批加入，不创建条目、不写 Tag。
- [ ] 点开未入架作品的章节仍静默加入，不弹窗且未打标签；拖拽导入、批量导入、重建下载索引、远程接管与 CLI/API 行为不变。
- [ ] 页面级测试覆盖单本本地加入、批量本地加入、重新加入、取消与静默加入。
