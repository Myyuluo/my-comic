# 10: 导出进度记录（Tracking）

**What to build:** 创建备份页增加「进度记录」勾选项；导出每部 Manga 的 Bangumi 追踪记录；该选项依赖「书架中的作品」。

**Blocked by:** 07（创建备份页与导出基础）

**Status:** ready-for-agent

- [ ] 创建备份页增加「进度记录」勾选项，默认勾选；取消「书架中的作品」时置灰。
- [ ] 勾选时，每部有 Bangumi 追踪数据的 Manga 导出追踪记录，包含同步 ID、远端作品 ID、最后阅读章节、状态、评分与相关时间。
- [ ] 没有追踪数据的 Manga 不写空记录；其他 tracker 当前不导出。
- [ ] 关闭「进度记录」时不写入追踪记录。
- [ ] 备份 seam 测试覆盖有追踪、无追踪与勾选依赖。
