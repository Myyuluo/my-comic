# 01: 统一移出书架弹窗与单本删除语义

**What to build:** 在线 Manga 作品页与本地 Manga 作品页的「移出书架」共用一个确认弹窗；移除粉/蓝说明块、「记住这些选择」与同步提示；提供两个默认不勾选的选项：同时删除本地文件、同时删除统计数据。本地 Manga 的原作文件可以在勾选后删除；文件删除先于数据库删除，失败时保留该 Manga 并报告；History 不被删除。

**Blocked by:** None（can start immediately）

**Status:** ready-for-agent

- [ ] 在线 Manga 作品页与本地 Manga 作品页点「移出书架」显示同一个弹窗，标题为「移出漫画书架」。
- [ ] 弹窗只保留标题、说明、两个勾选项与取消/删除按钮；不再出现粉/蓝说明块、「记住这些选择」与「未配置同步」提示。
- [ ] 单本说明为「把这部作品移出书架？阅读进度与已读标记会一并删除。」。
- [ ] 「同时删除本地文件」与「同时删除统计数据」每次打开都默认不勾选；此前保存的记住选择不再影响弹窗。
- [ ] 勾选「同时删除本地文件」时，在线 Manga 删除 Download library 中该作品的已下载章节文件；本地 Manga 删除 Local source root 中该作品的原作文件夹或文件。
- [ ] 文件删除先于数据库删除；文件删除失败时该 Manga 仍留在 Library 并显示失败提示；文件不存在视为已删除。
- [ ] 勾选「同时删除统计数据」时，该作品的阅读统计与查词/制卡计数被移除，统计页不再计入；在线与本地 Manga 均生效。
- [ ] 未勾选任何可选项时，只移出 Library，不删除本地文件与统计数据。
- [ ] 移出后 Reading progress、Chapter 已读标记与 Tag 分配被删除，History 保留。
- [ ] 取消弹窗不产生任何数据变化。
- [ ] 页面级测试覆盖上述行为（真实数据库 + 临时目录），并覆盖文件删除失败与文件缺失。
