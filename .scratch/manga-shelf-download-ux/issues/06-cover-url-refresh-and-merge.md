# 06: 在线封面元数据刷新与 URL 合并

**What to build:** 让在线漫画的封面 URL 能在签名过期后自愈：详情/封面刷新与章节刷新解耦，章节列表为空或抓取失败时仍持久化新的封面 URL；打开源搜索/详情页识别到已有书架作品时，把源当前返回的封面 URL 合并回该记录。

**Blocked by:** None（can start immediately）

**Status:** ready-for-agent

- [ ] 源详情刷新成功时，即使章节列表为空或章节抓取失败，也持久化新的系列元数据与封面 URL。
- [ ] 源返回空章节列表而本地已有非空章节时，保留旧章节缓存，不清空章节列表。
- [ ] 打开源搜索结果或源详情页并识别到已有书架记录时，把当前系列描述（至少封面 URL）合并回该记录，不要求用户手动刷新。
- [ ] 签名 URL 过期后，用户手动刷新作品页或重新打开对应源页面，书架封面恢复显示。
- [ ] 来源未安装/未启用时，作品页仍保持灰占位、不发起远程封面请求；书架若有本地封面则继续显示。
- [ ] 封面 URL 的刷新与合并不写入 Download library、不创建下载目录。
- [ ] 测试在在线元数据刷新与书架封面解析 seam 上覆盖：章节为空仍保存新 URL、旧章节保留、源页面合并 URL、过期 URL 自愈、来源缺失不请求。
- [ ] 不改变 Backup 导出/导入格式。
