# 01: 继续阅读与「读完」语义修正

**What to build:** 修正书架在线漫画的进度、续读与「读完」判定，使读者读书架漫画的任意一章（包括存储数组旧章在前、单章作品、导入章状态）后，书架顶部继续阅读胶囊能正确出现并指向最近阅读的作品；只有显式标记读完或读到规范阅读顺序最后一章末页才算读完。

**Blocked by:** None（can start immediately）

**Status:** ready-for-agent

- [ ] 存储数组旧章在前、当前停在第 1 话中间页的在线漫画被判定为「在读」，继续阅读胶囊出现并能打开该作品。
- [ ] 单章作品打开但未读完时被判定为「在读」，胶囊可选中；读到该章最后一页后才判定为「读完」。
- [ ] 读完多话作品的任一旧章只写该章已读，不写书级完成标记；只有读到规范阅读顺序最后一章的最后一页才写书级完成标记。
- [ ] 显式「标记已读完 / 取消已读完」仍然直接写/清书级完成标记，不受自动写入条件限制。
- [ ] 继续阅读胶囊只从书架成员中选择最近真正阅读过的在读作品；没有候选时隐藏；非书架漫画不参与。
- [ ] 书架的「在读 / 读完」统计、「阅读状态」筛选与继续阅读胶囊使用同一分类口径。
- [ ] 完成状态已知且未完成时，进度到 100% 不再自动判「读完」；没有完成状态信息的旧记录保留原有回退行为。
- [ ] 导入备份恢复的章级阅读状态可参与进度与最近阅读判定，即使本机没有阅读位置记录。
- [ ] 回归测试走真实书架数据管线（真实数据库行与章状态），不覆盖合成 `MediaItem.position / duration`；覆盖旧章在前、单章、完成旧章、完成最新章、非书架、导入章状态。
- [ ] 设置与书架视觉保持不变，遵守 ADR 0008。
