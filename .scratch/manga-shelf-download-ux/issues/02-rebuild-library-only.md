# 02: 重建下载索引只重链书架成员

**What to build:** 把「重建下载索引」收窄为只重链书架中已有漫画的恢复扫描：点击整行触发，扫描当前 Content root 的 `downloads` 与 `local`，只更新 `membership=true` 的 Manga 的下载关联；绝不把磁盘作品加入书架，也不改动非书架记录。

**Blocked by:** None（can start immediately）

**Status:** ready-for-agent

- [ ] 「重建下载索引」只扫描当前 Content root 的 `downloads` 与 `local`，不读取旧 Content root 或 `autobackup`。
- [ ] 只读取和重链 `membership=true` 的 Manga；非书架 Manga 不被读取、改写、重链或删除。
- [ ] 不创建任何 Manga 记录，不翻转 Library membership，不分配 Tag，不把 `downloads` / `local` 中书架没有的作品加入书架。
- [ ] 保留现有匹配顺序：`pages.json` 下载身份 → 已记录且仍在 `downloads` 内的路径 → `downloads` 无 manifest 目录的文件夹名回退；`local` 无 manifest 目录不按标题匹配。
- [ ] 不引入「本机章节」概念：源章节列表为空时不把磁盘容器合成为章节。
- [ ] 全程不移动、不复制、不删除、不重命名任何用户文件或映射。
- [ ] 行尾「重建」按钮移除，整行可点触发同一动作；确认框、可取消进度框与结果报告保留。
- [ ] 副标题使用：「重新关联书架中已有漫画的下载章节，适用于导入备份后有本地下载章节却显示未下载；不会删除记录或文件。」
- [ ] 报告不再出现「新增作品」统计；包含扫描书架条目、匹配、重链、缺失、跳过（含歧义）、失败与取消数量。
- [ ] 重复运行幂等，不产生重复记录或重复章节。
- [ ] 将发现/恢复辅助逻辑抽成可复用模块，供「检索已下载」使用；抽取本身不改变重建的用户可见行为。
- [ ] 测试覆盖设置动作 seam 与服务 seam：整行点击、仅书架成员、绝不新增、非书架行不变、文件不移动、幂等。
- [ ] 所有新增/修改文案在全部支持语言中同步，并重新生成访问器。
