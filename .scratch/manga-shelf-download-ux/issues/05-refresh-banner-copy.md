# 05: 刷新失败横幅文案

**What to build:** 修正漫画作品页刷新失败横幅：删除误导性的「显示的是本机已保存的章节」副标题，并把运行时失败标题改为「无法获取漫画信息，请重试或查看详情」；其他失败原因保留各自标题，但同样不再显示本机章节副标题。

**Blocked by:** None（can start immediately）

**Status:** ready-for-agent

- [ ] 运行时刷新失败横幅标题显示「无法获取漫画信息，请重试或查看详情」。
- [ ] 刷新失败横幅不再显示「显示的是本机已保存的章节」，无论失败原因是什么。
- [ ] 来源停用、平台不支持等其他失败原因仍显示各自的原因标题。
- [ ] 「重试」与「查看详情」动作及其可见性规则保持不变。
- [ ] 测试覆盖运行时失败、来源停用、平台不支持三种情况下的标题与副标题。
- [ ] 所有修改文案在全部支持语言中同步；不再使用的副标题 key 被删除或明确标记为待清理，并重新生成访问器。
