# 07: 下载页全局暂停 / 继续

**What to build:** 下载页新增持久化的「暂停」状态与右下角气泡胶囊全局按钮：按钮按队列状态在「全部暂停」与「全部继续」之间切换；暂停期间新任务保持暂停；全部继续恢复暂停任务并重试失败任务；继续下载复用页级续传。

**Blocked by:** 05（下载页任务可见性）

**Status:** ready-for-agent

- [ ] 新增持久化「暂停」任务状态；重启后暂停任务仍暂停。
- [ ] 下载页右下角显示气泡胶囊按钮（图标 + 文字）。
- [ ] 列表为空时按钮隐藏。
- [ ] 列表非空且所有任务都是暂停或失败时，按钮显示「全部继续」。
- [ ] 存在排队中或下载中任务时，按钮显示「全部暂停」。
- [ ] 点击「全部暂停」把所有排队中 / 下载中任务置为暂停；失败任务保持失败。
- [ ] 暂停期间新入队的章节以暂停状态入队，不会自动开始。
- [ ] 点击「全部继续」把暂停任务恢复为排队，并重试所有失败任务。
- [ ] 进行中 / 排队中的任务行没有暂停 / 继续按钮，但仍可单独取消。
- [ ] 继续下载复用 staging 页级续传，已完成的页不重复下载。
- [ ] 最后一张任务卡不被右下角按钮遮挡。
