# 01: 漫画页标签页签（书架 + 单选 + 数量）

**What to build:** 漫画页顶部的标签筛选从彩色多选 chip 改为分段胶囊页签：首项固定「书架」，其后是用户标签；单选；「书架」只收无标签漫画，有标签漫画只出现在对应标签下；每个页签显示当前会显示的漫画数量。旧的彩色多选 chip 与长按拖拽排序不再用于漫画页，其他媒体库的共享标签行为保持不变。

**Blocked by:** None（can start immediately）

**Status:** ready-for-agent

- [ ] 进入漫画页默认选中「书架」；应用运行期间保留当前页签，进程重启后回到「书架」。
- [ ] 标签栏为单选分段胶囊，首项「书架」固定最左，其余标签在右侧横向滚动；标签不显示自身颜色，选中只靠胶囊填充。
- [ ] 「书架」只显示没有任何用户标签的漫画；有标签的漫画不出现在「书架」。
- [ ] 有标签的漫画只出现在对应标签页签；多标签漫画在每个对应标签中都出现；不存在「全部」页签。
- [ ] 每个页签显示当前会显示的漫画数量（包括 0）；数量随现有搜索词与阅读状态筛选更新；标签名截断时数字不截断。
- [ ] 标签栏不再支持长按拖拽排序；页头「管理标签」入口仍可打开并完成标签管理。
- [ ] 现有搜索与阅读状态筛选在当前页签的集合内正常生效。
- [ ] 书籍 / 视频等其他媒体库的彩色多选标签筛选与拖拽排序行为不变。
