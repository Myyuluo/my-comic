# 06: 书架搜索扩围 + 漫画下载筛选 + 页签数量

**What to build:** 漫画页搜索从只匹配书名扩展到标题、作者、源分类与简介（不匹配用户标签）；「排序与筛选」新增「漫画下载」组（全部 / 已下载 / 未下载）；搜索、阅读状态与漫画下载筛选都只在当前页签的集合内生效，并驱动各页签数量实时更新。

**Blocked by:** 01（漫画页标签页签）

**Status:** ready-for-agent

- [ ] 搜索匹配显示标题、原始标题、作者行（作者优先、画师兜底）、源分类、简介。
- [ ] 搜索不匹配用户标签。
- [ ] 本地图源记录没有源分类 / 简介时，只匹配标题和作者。
- [ ] 搜索沿用现有归一化子串匹配（全角 / 假名 / 标点折叠、大小写不敏感）。
- [ ] 搜索只在当前页签的集合内生效；停在「书架」时不会出现带标签漫画的命中。
- [ ] 「排序与筛选」新增单选组「漫画下载」：全部（默认）/ 已下载 / 未下载；与阅读状态、当前页签是 AND 关系。
- [ ] 「已下载」表示至少有一章在本地可读：在线漫画按 Download library 至少一章完整落盘，本地图源按文件实际存在；Missing 不计为已下载。
- [ ] 每个页签数量在搜索、阅读状态、漫画下载筛选变化时同步更新；数量始终显示（包括 0）。
- [ ] 切换页签时保留搜索词，数量随当前筛选重新计算。
