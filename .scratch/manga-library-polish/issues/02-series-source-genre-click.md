# 02: 作品页源分类点击 → 全局搜索

**What to build:** 作品页展示来源提供的全部源分类（不设数量上限），每个源分类都可点击；点击效果与点击书名/作者一致：以该分类文字为关键词打开「搜索全部来源」并自动检索全部已启用的在线 Source。

**Blocked by:** None（can start immediately）

**Status:** ready-for-agent

- [ ] 作品页渲染来源提供的全部源分类，不再限制为 8 个。
- [ ] 每个源分类可点击，点击效果与点击书名/作者一致：以分类文字为关键词打开「搜索全部来源」并自动搜索全部已启用在线源。
- [ ] 没有可用在线源时仍打开搜索页，并显示搜索页自己的空态说明。
- [ ] 源分类具有与书名/作者一致的悬停反馈。
- [ ] 书名/作者原有的点击行为不变。
