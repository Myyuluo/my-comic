# 03: 漫画封面未读角标

**What to build:** 漫画封面右上角原本的书本图标改为未读章节数：没有未读章节时整个角标不显示；未读数按章的已读标记计算，读到一半的章也算未读；≥100 显示「99+」，角标宽度随内容伸缩。同时去掉漫画封面左上角的用户标签 chip，保留封面底部阅读进度条。

**Blocked by:** None（can start immediately）

**Status:** ready-for-agent

- [ ] 漫画封面右上角显示未读章节数，不再显示书本图标。
- [ ] 未读数按章节已读标记计算：没有已读标记的章计入，读到一半的章也计入。
- [ ] 未读数为 0 时角标完全不显示；≥100 显示「99+」；角标宽度随内容伸缩，数字清晰可读。
- [ ] 漫画封面左上角不再显示用户标签 chip；封面底部阅读进度条保留。
- [ ] 在线漫画与本地图源漫画适用同一规则。
- [ ] 从阅读器返回或批量标记已读后，未读数刷新。
- [ ] 漫画数量较多时，进入页面与滚动不因未读计算出现明显卡顿。
