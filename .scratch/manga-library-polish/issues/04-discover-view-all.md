# 04: 发现页聚合搜索「查看全部」

**What to build:** 发现页「搜索所有来源」的聚合搜索结果中，每个来源分区的标题行右侧新增「查看全部」；点击进入该来源自己的搜索页，搜索框预填当前关键词并自动执行搜索，返回后聚合页保留原状态。

**Blocked by:** None（can start immediately）

**Status:** ready-for-agent

- [ ] 聚合搜索结果的每个来源分区标题行右侧显示「查看全部」（文字 + 右箭头，复用现有样式）。
- [ ] 加载中、空结果、失败、有结果时都显示该入口。
- [ ] 点击后打开该来源自己的搜索页，搜索框预填当前关键词并自动执行搜索。
- [ ] 来源搜索页显示该关键词的完整结果并支持分页。
- [ ] 从来源搜索页返回后，聚合搜索页原有结果与状态保留。
- [ ] 普通提交搜索（不点「查看全部」）的现有行为不变。
