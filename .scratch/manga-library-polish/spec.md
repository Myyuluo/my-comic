# 漫画页标签页签、源分类跳转与下载页暂停（manga-library-polish）

Status: ready-for-agent
Date: 2026-11-09

## Problem Statement

漫画阅读的日常路径上有几处摩擦：

- 作品页展示了来源提供的分类（源分类），但只能看不能点；想按分类继续找书必须自己复制关键词再搜索。
- 漫画页顶部的用户标签仍是一排彩色多选 chip：多个标签同时生效时结果取交集，用户无法把标签当成互斥分类使用；也没有一个固定的「书架」落点来查看没有打标签的漫画。
- 封面右上角固定显示一个书本图标，不提供任何信息；左上角又重复显示用户标签 chip，占掉封面空间；用户看不出每部漫画还有多少章没读。
- 「排序与筛选」没有下载状态维度；搜索只匹配书名和原名，按作者、源分类或简介记住的漫画搜不到。
- 发现页的「搜索所有来源」结果每个来源只给一小条横滑结果，没有进入该来源完整结果的入口。
- 下载页会永久保留已完成和已取消的任务；也没有暂停能力，无法把整个下载队列停下来。

## Solution

- 作品页的所有源分类 chip 都可点击，行为与书名/作者一致：以分类名为关键词打开「搜索全部来源」并自动搜索；不限制显示数量。
- 漫画页标签栏改为浏览页「图源 / 发现」同款的分段胶囊：首项「书架」固定，其后是用户标签；单选；「书架」只收无标签漫画，有标签的漫画只出现在对应标签下；没有「全部」入口；每个页签显示当前会显示的漫画数量。
- 封面右上角改为未读章节数（0 时隐藏）；去掉封面左上角的用户标签 chip；保留底部阅读进度条。
- 「排序与筛选」新增「漫画下载」单选组（全部 / 已下载 / 未下载）；搜索扩展到书名、作者、源分类、简介，但仍只在当前页签的集合内生效。
- 发现页聚合搜索的每个来源分区新增「查看全部」，点击进入该来源的搜索页并预填、自动执行当前关键词。
- 下载页只展示可操作任务：完成即从列表消失、取消即删除任务行、失败保留并可「继续」重试；右下角新增全局「全部暂停 / 全部继续」气泡胶囊按钮，暂停/继续只由它控制。

## Implementation Decisions

### 术语与领域模型

- 用户自建分类统一称「标签（Tag）」；漫画页标签栏的首项称「书架页签」；来源提供的分类称「源分类（Source genre）」；下载任务新增「暂停（Paused）」状态。不再用「书签」指代标签。
- `GLOSSARY.md` 需同步：更新 Tag 的呈现方式（单选页签 + 数量，不再彩色多选 chip / 页内拖拽排序）；新增书架页签、源分类、暂停；更新视图页签条目（漫画页该位置现在是标签栏，首项为书架）；更新下载页条目（只列可操作任务、完成不展示、取消即移除、暂停全局化）。

### 漫画作品页

- 源分类的渲染上限移除：来源给多少个 genre 就渲染多少个，按自然换行排列。
- 每个源分类 chip 可点击，回调与书名/作者共用同一条导航：以当前显示的分类文字为关键词打开「搜索全部来源」，并自动检索全部已启用的在线 Source；没有运行时/可用来源时仍打开搜索页，由搜索页显示空态。
- 源分类 chip 的悬停反馈与作者 chip 一致。

### 漫画页标签栏

- 视觉形态使用浏览页「图源 / 发现」同款的分段胶囊（浮动、选中段 secondaryContainer 填充、弹性切换）；标签不显示自身颜色，选中只靠胶囊填充。
- 首项「书架」固定在最左；其余标签按标签管理页维护的顺序排列，放不下时在胶囊内横向滚动。
- 标签栏为单选：任一时刻恰好一个页签生效。默认「书架」；应用运行期间保留当前选择，进程重启后回到「书架」；只作用于漫画页。
- 归属语义是排他的：「书架」= 没有任何用户标签的漫画；有标签的漫画只出现在其标签页签中；多标签漫画在每个对应标签中都出现；不存在「全部」页签。
- 每个页签显示数量：数量 = 当前搜索词、阅读状态筛选、漫画下载筛选都生效后，该页签会显示的漫画数；无搜索/筛选时等于该页签总数。数量始终显示（包括 0）；数字使用小号、次要色，选中时随文字颜色；标签名截断，数字不截断。
- 标签栏不再提供长按拖拽排序；标签顺序仍在标签管理页调整。页头「管理标签」入口保留。
- 旧的彩色多选 chip 行为不再用于漫画页。共享标签筛选栏仍服务其他媒体库，其多选行为不变；漫画页使用独立的单选页签状态。

### 封面角标

- 漫画封面右上角使用现有封面角标组件显示未读章节数，不再显示书本图标。
- 未读章节数 = 当前章节列表中「没有已读标记」的章节数；读到一半（有页码但没有已读标记）也算未读；锁定章、未下载章同样计入。
- 未读数为 0 时整个角标不渲染。
- 数字 ≥100 时显示「99+」；角标宽度随内容伸缩，不再受原有固定方形尺寸限制；底色与字号沿用现有角标。
- 漫画封面左上角不再渲染用户标签 chip；其他媒体类型的封面行为不变。封面底部阅读进度条保留。
- 未读数需要批量计算（章节列表 + 每章已读状态），避免每张卡单独查库；进入页面、从阅读器返回、批量标记已读后刷新。

### 排序与筛选与搜索

- 「排序与筛选」菜单在「阅读状态」之后新增单选组「漫画下载」：全部（默认）/ 已下载 / 未下载。该组与阅读状态、当前页签是 AND 关系。
- 「已下载」的判定是「这本书至少有一章在本地可读」：在线漫画看 Download library 中是否至少有一章完整落盘；本地图源漫画看源文件是否实际存在。文件缺失（Missing）不计为已下载。
- 搜索匹配字段：显示标题、原始标题、作者行（作者优先、画师兜底）、源分类、简介。用户标签不参与匹配。本地图源的记录没有源分类/简介，只匹配标题与作者。
- 匹配方式沿用书架现有搜索的归一化子串匹配（全角/假名/标点折叠，大小写不敏感）。
- 搜索、阅读状态筛选、漫画下载筛选都只在当前页签的集合内生效；结果不会跨页签汇总到「书架」。
- 切换页签时保留搜索词并重新计算各页签数量；数量本身承担「其他页签是否有命中」的提示，不再另加提示条。

### 发现页聚合搜索

- 聚合搜索结果中每个来源分区的标题行右侧新增「查看全部」，复用发现页现有的「查看全部」按钮样式（文字 + 右箭头）。
- 「查看全部」在加载中、空结果、失败、有结果时都显示，不随分区状态隐藏。
- 点击后打开该来源自己的搜索页，搜索框预填当前关键词并自动执行搜索；来源页显示该关键词的完整结果（可分页），返回后聚合页保留原有状态。
- 来源搜索页需要新增「初始关键词 + 自动搜索」入口；现有搜索（提交才搜）行为不变。

### 下载页

- 下载页只列出可操作任务，已完成任务不再出现。
- 完成：任务从列表消失，下载文件与 Download library 映射保留，仍可阅读。数据库中的任务行保留，仅用于作品页判断「文件缺失（Missing）」，不再在下载页展示。
- 取消：正在下载或排队中的任务取消后直接删除任务行，并清理该任务的半成品 staging / 临时压缩包；列表立即移除，不保留「已取消」行。
- 失败：任务保留在列表中，行内操作显示「继续」；点击后同一任务行复位为排队并重试。失败任务不自动重试，除非用户点击「继续」或「全部继续」。
- 暂停：新增持久化的「暂停」任务状态。暂停/继续只由下载页右下角的全局按钮控制；进行中/排队中的任务行不再有暂停/继续按钮，但仍可单独取消。
- 「全部暂停」：把所有排队中和下载中的任务置为暂停；失败任务保持失败，不做处理。
- 暂停期间新入队的章节直接以暂停入队，不会自动开始下载。
- 「全部继续」：把暂停任务恢复为排队，并重试所有失败任务。
- 全局按钮状态机：列表为空 → 隐藏；列表非空且所有任务都是暂停或失败 → 显示「全部继续」；其余情况（存在排队中或下载中任务）→ 显示「全部暂停」。
- 按钮形态：右下角气泡胶囊，图标 + 文字；列表底部需要补足留白，避免最后一张卡被按钮遮挡。
- 暂停状态持久化：重启后暂停任务仍暂停，全局按钮显示「全部继续」。
- 继续下载复用现有 staging 页级续传：已完整落地的页不重复下载。

### 数据与接口

- 新增「暂停」任务状态值；worker 只领取排队中的任务。暂停正在运行的任务时停止取页但保留 staging；恢复时重新入队即可续传。暂停不是终态，不计入「已完成/失败/已取消」的结束判定。
- 新增批量读取「每部漫画的未读章节数」的数据接口（章节列表 + 章节已读状态），供漫画页一次性计算角标。
- 新增批量读取「每部漫画是否至少有一章本地可读」的数据接口：在线漫画走 Download library，本地图源走文件存在性；供漫画下载筛选与页签数量使用。
- 每个页签的数量与筛选可基于已加载的书架条目、标签映射、下载状态在内存中计算；不要求新增数据库表。任务状态新增字符串值，不需要 schema 迁移。
- 来源搜索页新增初始关键词参数与自动搜索行为。
- 作品页头部新增源分类点击回调，沿用现有的「搜索全部来源」导航。
- 共享下载任务卡不需要新增每行暂停操作；只需支持失败行的「继续」文案与现有取消操作。

### 共享组件边界

- 共享标签筛选栏继续为其他媒体库提供彩色多选 chip 与拖拽排序；漫画页使用新的单选页签形态。共享的多选标签选中状态不改为单选，避免影响其他库。
- 共享封面卡只在漫画条目上隐藏标签 chip；其他媒体类型的封面不改。
- 新形态复用现有组件与主题（分段胶囊、封面角标、FAB、发现页「查看全部」按钮），不引入新的视觉语言。

### 文档

- `GLOSSARY.md` 按「术语与领域模型」更新。
- 新增 ADR：漫画页以标签为页签、书架只收无标签漫画（包含经用户批准的、偏离 Fushi 原版 tag chip 的分段胶囊形态）。
- 新增 ADR：下载页只显示可操作任务，暂停/继续全局化（记录放弃单行暂停的取舍）。

## Testing Decisions

- 好测试的标准：只断言用户可见的公开行为（页面渲染、导航结果、按钮状态、列表内容、文件是否保留），不扫描源码、不调用私有方法、不断言内部实现细节。
- 使用真实的内存数据库与各测试已有的假运行时/假适配器；下载相关的失败与暂停使用可控的假 adapter 与手动推进，避免依赖真实计时。
- 优先使用页面级公开 widget 作为 seam；不新增仅为测试存在的 seam。

拟采用的 4 个现有 seam：

1. **漫画页（`ReaderFushiHistoryPage`，`mangaOnly: true`）**：覆盖第 2–7 条的主要用户行为。
   - 默认选中「书架」；「书架」只显示无标签漫画；有标签漫画不出现在「书架」；多标签漫画在每个标签下出现；单选切换。
   - 每个页签数量在搜索、阅读状态筛选、漫画下载筛选下正确更新；0 也显示。
   - 搜索匹配作者、源分类、简介；不匹配用户标签；只返回当前页签的命中。
   - 漫画下载筛选的三种取值与 AND 组合。
   - 封面未读角标：0 隐藏、99+、读到一半算未读；封面不再显示用户标签 chip。
   - prior art：`reader_shelf_tag_filter_empty_state_test`、`reader_shelf_read_status_filter_persist_test`、`manga_shelf_mark_read_cascade_test`、`reader_bookshelf_badge_size_test`、`shared_tag_filter_bar_guard_test`。
2. **作品页（`MangaSeriesPage`）**：覆盖第 1 条。
   - 源分类数量超过 8 时全部渲染。
   - 每个源分类可点击，点击以分类文字为关键词触发「搜索全部来源」。
   - 没有可用来源时仍触发导航。
   - prior art：`manga_series_page_download_first_test`、`manga_series_page_remove_from_shelf_test`。
3. **聚合搜索页（`MangaGlobalSearchPage`）**：覆盖第 8 条。
   - 每个来源分区都有「查看全部」；加载中/空/失败/有结果时不隐藏。
   - 点击后打开该来源搜索页，关键词已预填并自动搜索。
   - prior art：`manga_global_search_page_test`、`manga_global_search_runner_test`。
4. **下载页（`DownloadsPage`）+ 真实 `MangaDownloadService`（内存 DB + 假 adapter）**：覆盖第 9–11 条。
   - 已完成任务不渲染、已取消任务行被删除、失败任务显示「继续」并可重试。
   - 全局按钮三种状态：空列表隐藏、全部暂停/失败显示「全部继续」、存在排队/下载中显示「全部暂停」。
   - 「全部暂停」后重启服务仍为暂停；暂停期间新入队任务保持暂停。
   - 「全部继续」恢复暂停任务并重试失败任务。
   - 暂停/继续复用 staging 续传，已完整页不重复取。
   - prior art：`downloads_page_test`、`manga_download_service_test`、`manga_chapter_download_state_test`、`manga_download_jobs_delete_cascade_test`。

回归要求：现有标签筛选栏、书架筛选、作品页与下载页测试必须继续通过；共享标签筛选栏与其他媒体库的多选行为不变。

## Out of Scope

- 单行暂停/继续（已被用户明确撤销；暂停/继续只由全局按钮控制）。
- 「全部」页签或跨页签聚合搜索结果页。
- 搜索用户标签。
- 其他媒体库（书籍 / 视频）的标签筛选行为改动。
- 标签栏显示标签颜色或长按拖拽排序。
- 下载历史页或已完成任务的保留/清理界面。
- 未读数、未读角标扩展到书籍 / 视频。
- 其他数据库 schema 迁移（「暂停」状态值因表级 CHECK 约束需要一次 v3→v4 的下载任务表重建，已在本次范围内）。
- 重新设计下载任务卡的整体视觉（只在现有卡片上调整可见性与操作）。

## Further Notes

- **UI fidelity**：分段胶囊直接复用浏览页「图源 / 发现」的现有组件；它偏离 Fushi v3.0.0 原版彩色 tag chip，属于用户在 2026-11-08/09 明确批准的 UI 改动，需在 ADR 中记录（ADR 0008 要求显式批准）。
- **性能**：页签数量、下载筛选、未读角标都应在进入页面或数据变化时批量计算；避免逐卡查库或逐卡 `File.exists()`。本地图源的「文件存在」判定可随书架加载缓存一次，下载完成/删除后再刷新。
- **计数口径**：多标签漫画在每个标签中各计一次，因此各页签数量之和可能大于书架总数；这是排他归属下的预期行为。
- **Missing 与已下载**：完成记录保留在数据库中是为了让作品页仍能显示「文件缺失」；缺失文件不计为「已下载」，因为它不可读。
- **暂停不是终态**：现有「已完成 / 失败 / 已取消」的结束判定不能把暂停算进去；取消暂停任务仍走现有取消路径并删除任务行。
- **建议工单拆分**（供后续建 ticket 参考）：
  1. 作品页源分类点击 → 全局搜索
  2. 漫画页标签栏（单选、书架、数量、分段胶囊形态）
  3. 封面角标（未读数、移除标签 chip）
  4. 书架搜索扩围 + 漫画下载筛选 + 页签数量
  5. 发现页聚合搜索「查看全部」
  6. 下载页可见性（完成隐藏、取消移除、失败继续）
  7. 下载页全局暂停/继续
  8. GLOSSARY + ADR 更新
