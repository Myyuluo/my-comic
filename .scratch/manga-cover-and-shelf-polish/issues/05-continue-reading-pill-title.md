# 05: 继续阅读胶囊显示书名

**What to build:** 书架顶部继续阅读胶囊在「继续阅读」下方增加漫画书名：小号灰黑色，宽度与「继续阅读」一致，超出省略；完整书名仍在 tooltip 中，胶囊整体保持单一点击目标。

**Blocked by:** None（can start immediately）

**Status:** ready-for-agent

- [ ] 胶囊第二行显示当前作品的显示标题（`getDisplayTitleFromMediaItem`，含改名覆盖），不是数据库原始标题。
- [ ] 书名使用小号灰黑色文字（MD3 `onVariant`，Apple `secondaryLabel`），不是纯黑，也不抢主色「继续阅读」的视觉重心。
- [ ] 书名宽度按本地化「继续阅读」的实际渲染宽度通过 `TextPainter` 测量并约束；`maxLines: 1`，超出显示省略号。
- [ ] 完整书名保留在悬停 tooltip 中；胶囊整体仍是单一点击目标，点击任意位置打开当前作品。
- [ ] 桌面 MD3 的顶部 chrome 行高度不变；Apple 渲染路径不被裁切，如增高胶囊表面则页面 chrome 正确适配。
- [ ] 没有继续阅读候选时胶囊保持隐藏，不出现空书名行。
- [ ] 更新现有「胶囊不显示书名」测试，并新增/扩展：书名可见、改名覆盖、宽度/省略号、tooltip、无候选隐藏。
- [ ] 按 ADR 0008 要求补 ADR 0016 修订，记录用户批准的「胶囊显示书名」UI 变更；不改其他书架视觉。
