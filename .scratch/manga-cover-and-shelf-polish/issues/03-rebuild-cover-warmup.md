# 03: 重建下载索引预热第一页封面

**What to build:** 运行「重建下载索引」时，为书架中已有、有本地完整文件但缺封面的 Manga 预热生成第一页封面；只处理 Library 成员，不改变重建只重链、不新增的语义。

**Blocked by:** 02（缺失封面时从第一页生成封面）

**Status:** ready-for-agent

- [ ] 重建重链书架成员时，对 `membership=true`、有完整本地 Chapter container、且没有可用本地/远程/生成封面的 Manga 生成并缓存第一页封面。
- [ ] 只处理 Library 成员；不创建 Manga、不改变 membership、不分配 Tag、不移动/复制/删除文件。
- [ ] 缓存缺失或 sentinel 过期时才生成；重复运行幂等，不重复生成同一封面。
- [ ] 报告包含生成、更新、跳过与失败的封面数量；封面失败不阻断重建，也不把作品计为重建失败。
- [ ] 已有本地 `cover.*` 或可用远程封面的作品不被生成封面覆盖。
- [ ] 测试覆盖：源未安装 + 本地 CBZ 在重建后获得封面；有远程封面的作品不被覆盖；非书架作品被跳过；坏页计入失败；重复运行幂等。
- [ ] 不新增数据库 schema，不改变 Backup 格式。
