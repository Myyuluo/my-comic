# 03: Manga 作品页头部：移除状态标签 + 书名/作者链接

**What to build:** Manga 作品页左侧栏移除「已入库」「外部来源」两枚状态标签，保留「扩展源」，剩余内容自然上移。书名与作者名变为可点击：点击书名以书名为关键词、点击作者以作者名为关键词，打开「搜索全部来源」页并自动执行搜索，检索全部已启用的在线 Source。悬停时书名出现下划线、作者 chip 提亮，鼠标指针保持默认，静止外观不变，只响应鼠标点击。本地卷与互联对端作品同样生效；共用详情组件通过可选回调隔离，小说作品页零变化。

**Blocked by:** None（can start immediately）

**Status:** ready-for-agent

- [ ] Manga 作品页左侧栏不再显示「已入库」「外部来源」，不留空白占位。
- [ ] 「扩展源」标签仍然显示。
- [ ] 点击书名打开「搜索全部来源」页，并以书名自动执行搜索。
- [ ] 点击作者名打开同一搜索页，并以作者名自动执行搜索。
- [ ] 搜索范围是全部已启用的在线 Source（Source 自身启用且提供它的 Extension 也启用）。
- [ ] 书名悬停出现下划线、作者 chip 悬停提亮；鼠标指针保持默认；静止外观不变；只响应鼠标点击。
- [ ] 本地卷与互联对端作品的标题、作者同样可点击，行为与在线漫画一致。
- [ ] 窄窗口下标题与作者显示在页面顶部时同样可点击。
- [ ] 没有可用在线 Source 时显示搜索页自带空态，不额外出现「去装来源」按钮。
- [ ] 平台不支持扩展运行时时，点击书名或作者安全无操作，不崩溃。
- [ ] 小说作品页的标题、作者与标签外观和行为保持原样。
- [ ] GLOSSARY 已新增「Manga 作品页」与「全局搜索（搜索全部来源）」。
- [ ] 相关测试已新增/更新，`flutter analyze` 通过。
