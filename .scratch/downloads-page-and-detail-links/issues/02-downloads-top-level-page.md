# 02: 下载视图迁出浏览页，成为一级「下载」页

**What to build:** 下载从浏览页的视图页签迁出，成为一级导航页「下载」，位于浏览之后、设置之前。下载页顶部只有「下载」标题，固定展开、向下滚动不收起，不显示任何视图页签；内容为现有的简单下载任务列表与空态提示，切走再回来保留状态。浏览页删除「下载」视图页签及相关死代码，剩余视图为「在线源」「发现」「导入」。原下载列表被标题遮挡的问题随迁移消失；桌面 ctl 的 downloads 导航改开新下载页，browse 导航不变。

**Blocked by:** 01 固定导航：Manga 与浏览常驻

**Status:** resolved

- [x] 一级导航显示 Manga → 浏览 → 下载 → 设置；「下载」名称来自字符串资源，图标复用现有下载图标。
- [x] 下载页顶部只显示「下载」标题，无视图页签；向下滚动时标题不收起。
- [x] 下载列表首张卡片完整显示在标题下方，不再被遮挡，列表可正常滚动。
- [x] 下载任务卡片的展开、重试、取消、清除等既有行为不变。
- [x] 没有下载任务时显示空态提示。
- [x] 切换到其它一级页面再返回下载页，滚动位置与列表状态保留。

- [x] 浏览页下载视图相关的死状态与死代码已删除；不启用富任务浏览器（摘要/筛选/搜索/批量工具）。
