# 备份导入后的体验修复（manga-backup-import-ux）

Status: ready-for-agent
Date: 2026-11-10

## Problem Statement

漫画读者从 Mihon 导入 `.tachibk` 后，会遇到四个直接影响使用的问题：

1. **导入完成弹窗排版粗糙**：正文每一行都紧贴弹窗左边缘，标题/图标居中而正文零内边距，信息没有分组；缺失来源等重要提示与普通统计混在一起。创建备份的结果弹窗也有同样的贴边问题。
2. **导入作品全部是灰色封面**：备份只提供远程封面 URL，没有本地封面文件；书架只读取本地封面路径，从不使用备份里已保存的 `series.coverUrl`，所以所有导入作品都显示灰色占位。
3. **已安装扩展的作品仍无法阅读**：导入时若扩展尚未安装，条目会持久化为 `mihon.unavailable` 占位来源。之后即使安装了对应扩展，条目也不会重新解析；打开章节时报 `sourceDisabled`，下载也失败。作品页还会直接显示 `mihon.unavailable` 这个内部占位值。
4. **导入后标签页签不刷新**：分类已经按名称写成 Tag，Tag 分配也已写入，但书架顶部的 `allTagsProvider` / `bookTagMapProvider` 是缓存型 Provider，导入流程没有 invalidate。用户必须进入「管理标签」页再退出，标签页签和重新归属的作品才出现。

当前数据库可复现：9 部导入作品中，`cover_path` 全为空；9 部都持久化为 `mihon.unavailable`；zaimanhua 与 vomic 扩展已安装且启用，18comic 未安装；1 个 Tag、3 条 Tag 分配已写入但书架没有显示对应页签。

## Solution

- 重新设计导入完成弹窗：使用现有 Fushi 弹窗/卡片/notice 组件，补足内边距，按「书架与阅读」「设置与来源」分组，缺失来源使用 warning notice 突出展示；隐藏零值诊断行。创建备份结果弹窗同步补足 padding。
- 书架封面与作品页封面在本地封面不存在时，回退到备份已存的 `series.coverUrl`，通过现有 HTTP 图片缓存懒加载；加载失败继续使用占位封面。
- Mihon 来源解析增加按数字 `sourceId` 的运行时回退：先精确匹配 `(extensionPackage, sourceId)`，再按 `sourceId` 匹配已启用 Source。保持条目的 `extensionPackage`、`bookKey`、`uid` 不变，因此阅读位置、章节状态、History、Tag 与下载映射都不受影响。安装 zaimanhua/vomic 后，对应作品无需重新导入即可阅读。
- 对确实未安装的来源：导入时保存备份里的来源名称；作品页显示「来源未安装：<名称>」而不是 `mihon.unavailable`；章节打开失败时给出中文提示并引导用户自行安装扩展。不提供跳转扩展商店的按钮，也不自动安装扩展。
- 导入成功后成对 invalidate `allTagsProvider` 与 `bookTagMapProvider`，让标签页签与作品归属立即刷新；继续遵守 ADR 0016：带 Tag 的作品只出现在标签页签，「书架」只显示未打标签的作品。

## User Stories

### 导入完成弹窗

1. 作为漫画读者，我希望导入完成弹窗的正文有正常的左右内边距，以便文字不再紧贴弹窗边缘。
2. 作为漫画读者，我希望弹窗顶部有一个居中图标、标题和一行简短副标题，以便一眼知道导入完成并看到处理总量。
3. 作为漫画读者，我希望「书架与阅读」信息集中在一张卡片里，以便快速看到新增、合并、跳过、失败、分类、阅读进度与 History。
4. 作为漫画读者，我希望「设置与来源」信息集中在另一张卡片里，以便区分书籍数据与设置数据。
5. 作为漫画读者，我希望所有为零的次要诊断行被隐藏，以便弹窗不被「跳过 0」之类的噪音填满。
6. 作为漫画读者，我希望书架的主计数（新增/合并/跳过/失败）始终显示，以便知道导入是否完整。
7. 作为漫画读者，我希望缺失来源用 warning 色的 notice 展示，以便不会漏看。
8. 作为漫画读者，我希望 notice 里列出缺失来源名称，并提示安装对应扩展后即可阅读，以便知道下一步要做什么。
9. 作为漫画读者，我希望 notice 不提供跳转扩展商店的按钮，以便弹窗保持只读、不新增导航。
10. 作为漫画读者，我希望「完成」按钮仍在底部右侧，以便与现有弹窗操作习惯一致。
11. 作为漫画读者，我希望没有缺失来源时不显示 warning notice，以便正常导入保持简洁。
12. 作为漫画读者，我希望空备份或全失败时仍能看到清晰的结果与原因，以便知道导入没有成功。
13. 作为漫画读者，我希望创建备份的结果弹窗也补足内边距，以便备份结果不再贴左。
14. 作为漫画读者，我希望弹窗在窄窗口或高缩放下仍可滚动、不溢出，以便所有信息可达。

### 导入作品封面

15. 作为漫画读者，我希望导入的 Library 作品在本地没有封面文件时显示备份里的远程封面，以便书架不再是清一色灰色。
16. 作为漫画读者，我希望本地封面文件仍然优先，以便我没有手动设置的封面不会被远程图覆盖。
17. 作为漫画读者，我希望远程封面通过现有图片缓存加载，以便重复滚动时不会反复下载。
18. 作为漫画读者，我希望远程封面加载失败时显示现有占位封面，以便不会出现破图。
19. 作为漫画读者，我希望作品页的封面也遵循「本地优先、远程回退」，以便书架与作品页一致。
20. 作为漫画读者，我希望远程封面回退不依赖 Source 是否安装，以便来源缺失的作品也能显示备份里的封面。
21. 作为漫画读者，我希望不会因为远程封面回退而改变本地封面缓存/最近可用封面的语义，以便离线行为保持稳定。
22. 作为漫画读者，我希望导入时不强制下载所有封面，以便大批量导入不会因为网络变慢或卡住。
23. 作为漫画读者，我希望没有封面 URL 的作品继续使用占位封面，以便不会伪造封面。
24. 作为漫画读者，我希望远程封面 URL 过期或被防盗链拦截时只影响该作品，以便其他作品正常显示。

### 已安装扩展的导入作品

25. 作为漫画读者，我希望导入时扩展尚未安装、但后来安装了对应扩展的作品可以直接阅读，不需要重新导入。
26. 作为漫画读者，我希望打开作品页时来源标签显示真实来源名称，而不是 `mihon.unavailable`。
27. 作为漫画读者，我希望打开章节时能通过数字 sourceId 找到已安装的 Source，以便正常加载页面。
28. 作为漫画读者，我希望来源解析先精确匹配扩展包与 sourceId，再按 sourceId 回退，以便不会优先误用其他扩展。
29. 作为漫画读者，我希望同一 sourceId 对应多个已启用来源时不要随意选择，以便不会打开错误的来源。
30. 作为漫画读者，我希望运行时回退不修改条目的 `extensionPackage`、`bookKey` 或 `uid`，以便阅读位置、章节状态、History、Tag 与下载映射全部保留。
31. 作为漫画读者，我希望重新导入不是恢复可读的必要步骤，以便不丢失本机数据。
32. 作为漫画读者，我希望从已安装来源浏览到同一部作品时能识别已有的导入条目，以便不会创建重复的 Library 条目。
33. 作为漫画读者，我希望刷新章节、加载页面、下载章节与获取封面都使用同一个来源解析规则，以便行为一致。
34. 作为漫画读者，我希望扩展被停用或卸载时仍按现有「来源未安装或已停用」语义降级，以便不会崩溃。
35. 作为漫画读者，我希望已下载的章节不依赖 Source 也能打开，以便离线阅读保持可用。

### 来源确实未安装

36. 作为漫画读者，我希望导入时保存备份里的来源名称，以便之后能显示「来源未安装：再漫画」而不是内部占位值。
37. 作为漫画读者，我希望作品页的来源标签在来源缺失时显示「来源未安装」及已知名称，以便知道缺的是哪个扩展。
38. 作为漫画读者，我希望来源缺失时作品页明确说明当前只能看本机已保存的章节，以便理解为什么不能刷新或阅读。
39. 作为漫画读者，我希望打开章节失败时看到中文提示「来源未安装，请先安装对应扩展后重试」，以便知道如何解决。
40. 作为漫画读者，我希望下载章节失败时也看到同一类中文提示，以便不会只看到英文内部错误。
41. 作为漫画读者，我希望应用不会自动安装扩展，以便安装行为保持由我控制。
42. 作为漫画读者，我希望缺失来源提示不新增跳转按钮，以便保持现有导航结构。
43. 作为漫画读者，我希望来源名称未知时仍显示「来源未安装」，以便旧备份也能有可读的降级文案。
44. 作为漫画读者，我希望安装扩展后再次打开作品即可阅读，不需要重启应用。
45. 作为漫画读者，我希望来源缺失的作品仍保留在 Library 中，以便安装扩展后继续使用原条目。

### 标签页签即时刷新

46. 作为漫画读者，我希望导入成功后书架顶部的标签页签立即出现，不需要进入「管理标签」页再退出。
47. 作为漫画读者，我希望标签页签的数量立即正确，以便知道每个标签下有多少作品。
48. 作为漫画读者，我希望导入后带 Tag 的作品立即从「书架」页签移到对应标签页签，以便符合现有归属规则。
49. 作为漫画读者，我希望导入失败或取消时不触发标签刷新，以便没有数据变化就不重建界面。
50. 作为漫画读者，我希望导入后当前选中的页签保持不变，除非该 Tag 已被删除，以便不会突然跳转。
51. 作为漫画读者，我希望导入报告弹窗显示期间或关闭后，背后的书架已经是最新状态，以便关闭弹窗就能看到结果。
52. 作为漫画读者，我希望没有 Tag 的备份导入后仍只有「书架」页签，以便零 Tag 场景不出现空页签。
53. 作为漫画读者，我希望重复导入同一备份时标签页签保持幂等，以便不会重复出现或重复计数。
54. 作为漫画读者，我希望标签页签的排序继续使用分类 order，以便与备份顺序一致。
55. 作为漫画读者，我希望这次刷新修复不改变标签管理页、标签选择器或批量打标签的现有行为。

### 综合验收

56. 作为漫画读者，我希望用当前这份 9 部作品的数据库验收时，8 部显示远程封面，18comic 那部因 URL 不可达继续占位。
57. 作为漫画读者，我希望 zaimanhua/vomic 的 8 部作品在安装扩展后立即可读，18comic 那部在安装扩展前保持「来源未安装」。
58. 作为漫画读者，我希望导入完成弹窗不再出现文字贴左、信息混杂的问题。
59. 作为漫画读者，我希望上述修复不需要删除数据库、不需要重新导入、不需要重建下载索引。
60. 作为漫画读者，我希望修复过程中不改变 ADR 0016 的「书架 = 无 Tag」规则，也不改变 ADR 0008 的 UI 体系。

## Implementation Decisions

### 导入完成弹窗

- 复用现有 Fushi 弹窗、卡片、notice、hero icon 与 spacing tokens；不引入新视觉语言。
- 外层使用 `FushiDialogFrame` + `FushiModalSheetFrame`，显式提供左右内边距（与现有导入弹窗 prior art 一致，约一个 card spacing），并避免嵌套滚动。
- 顶部：hero 图标 + 标题「备份导入完成」+ 副标题显示本次处理的作品总数（如「共处理 9 部作品」）。
- 正文分两张卡片：
  - 「书架与阅读」：书架新增/合并/跳过/失败；分类新建/已存在；阅读进度章节状态；History；未入架 History（有数据时）；追踪（有数据时）。
  - 「设置与来源」：应用设置补齐/跳过；来源偏好导入/跳过；扩展仓库新增/合并/跳过（有数据时）。
- 主计数始终显示；只用于诊断的零值行隐藏。缺失来源使用 warning 色 notice，列出来源名称并提示安装对应扩展后可阅读；notice 不提供按钮。
- 「完成」保持底部右侧。报告弹窗保持可滚动；窄窗口/高缩放不溢出。
- 创建备份结果弹窗同样补足 body padding，避免同类贴边问题。
- 新增 report dialog 的页面级 widget 测试，断言分组、内边距、零值隐藏、缺失来源 notice 与无按钮。

### 导入作品封面

- Library 封面解析顺序：显式 `cover_path` → 本地 `cover.jpg/jpeg/png` → 备份 `sourceMetadata` 中 `series.coverUrl` → 占位封面。
- 远程封面只作为 `MediaItem.imageUrl` 返回，由现有 HTTP 图片缓存懒加载；不写入本地「最近可用封面」缓存，保持 BUG-513 的本地语义。
- 作品页封面同样使用本地优先、`series.coverUrl` 回退，并以占位封面作为失败/空值兜底。
- 不回退时要求 Source 已安装；来源缺失的作品也能显示远程封面。
- 导入阶段不下载封面；不新增封面预取队列；URL 过期、防盗链或网络失败时继续占位。
- 远程封面 URL 为空时不伪造；不改变封面文件、缓存键与离线行为。

### 导入作品的 Source 重解析

- 来源解析规则统一为：先精确匹配 `(extensionPackage, sourceId)` 且启用；若占位来源或没有精确匹配，则按数字 `sourceId` 匹配已启用 Source；同一 sourceId 命中多个包时视为歧义，不随意选择。最终仍由现有扩展安装/启用检查决定是否可用。
- 运行时回退覆盖刷新章节、加载章节页面、下载章节、获取封面与来源名称解析。
- 条目身份保持不变：不修改 `sourceMetadata.extensionPackage`、`bookKey`、`uid`、History 的 source identity 或下载 manifest。这样阅读位置、章节状态、History、Tag、下载映射都不需要迁移。
- `find`/重复检测增加按 `(sourceId, series key)` 的回退：从已安装来源浏览同一部作品时命中已有占位条目，而不是新建重复条目。
- 不实现软修复（改写 extensionPackage）或硬修复（重算 bookKey）；不在扩展安装/启动时批量迁移。
- 语言范围与同源多语言 chip 对占位条目的处理不在本次范围内；它们可以继续按存储的扩展包判断。

### 缺失来源的展示

- 导入时把备份 `BackupSource` 的 sourceId → 名称映射写入占位条目的 source metadata（可选字段，旧条目可为空）。安装来源后名称可从 Source 表读取。
- 作品页在来源缺失时显示「来源未安装」+ 已知名称（如「来源未安装：再漫画」），不显示 `mihon.unavailable`。
- 作品页说明当前只展示本机已保存的章节；刷新/阅读需要安装扩展。
- 章节打开或下载失败时，把 `sourceDisabled` 映射为中文提示「来源未安装，请先安装对应扩展后重试」，不再直接展示英文内部错误。
- 不新增「打开扩展商店」按钮；不自动安装扩展；不把缺失来源的作品从 Library 隐藏或删除。
- 名称未知时退化为「来源未安装」；来源 ID 不作为主要用户文案。

### 标签页签刷新

- 导入成功且报告非空后，在导入流程中成对 invalidate `allTagsProvider` 与 `bookTagMapProvider`；必要时同时 invalidate 共享筛选 provider。复用「管理标签」页退出时的刷新语义。
- 不把 Provider 改成 Drift stream；不重构标签管理/选择器/批量打标签路径。
- 继续遵守 ADR 0016：刷新后「书架」只显示无 Tag 作品，带 Tag 作品只出现在标签页签；标签顺序来自分类 order。
- 导入失败或取消不触发刷新。空备份/零 Tag 场景保持只有「书架」页签。
- 重复导入保持幂等；当前页签选择保持不变，除非选中 Tag 被删除。

### 文档与基线

- 更新 `GLOSSARY.md`：新增 Missing source（缺失来源）——被 Library 作品引用、但对应 Source 未安装/未启用；作品保留、封面与已下载章节可用、阅读需安装扩展；运行时按 sourceId 解析，不改变条目身份。
- 更新 ADR 0019 或新增 ADR：记录来源运行时回退、封面远程回退、缺失来源文案与「不做身份迁移」的边界。
- 在 ADR 0008 约束下记录本次 UI 改动是用户逐项批准的：复用 Fushi 组件，不引入新视觉体系。
- 新工作基于 `integration/manga-ux-backup-batch`（tip `e9e13380`）新建 follow-up 分支；spec/tickets 作为第一笔本地存档提交。
- 真实 `.tachibk` 与运行数据库不提交；自动化测试使用合成 fixture 与临时数据库。

## Testing Decisions

- 好测试只断言用户可见行为与数据结果，不测试私有方法、widget 结构或实现细节。页面级测试挂载真实页面，使用真实数据库与可控的 Mihon runtime/Source 注册表；备份测试使用现有合成 `.tachibk` fixture 与真实数据库。
- 只使用两个现有 seam，不新增更低层或更高层 seam：
  1. 页面级 widget/集成 seam：真实数据库 + 可控 Source/下载服务 + 真实偏好库。用于导入报告弹窗、书架/作品页封面、来源缺失文案、章节失败提示与标签页签刷新。
  2. 备份 fixture/import-service seam：合成 `.tachibk` + 真实数据库。用于来源名称持久化、占位条目身份与重复检测。
- 覆盖模块：

## Out of Scope

- 自动安装扩展或从弹窗跳转扩展商店。
- 在导入阶段下载/缓存所有封面。
- 通过 Source 代理获取需要 headers/cookies 的封面（18comic 的防盗链/超时不在本次修复内）。
- 改写 `extensionPackage`、重算 `bookKey` 或迁移 uid/history/download manifest。
- 把标签 Provider 改成 Drift stream 的全局响应式重构。
- 改变 ADR 0016 的「书架 = 无 Tag」规则。
- 占位条目的同源多语言 chip、language scope 与精确包名展示。
- 让真正未安装的来源在不安装扩展的情况下可读。
- 自动重建下载索引或修复已下载章节的 manifest。
- 其他媒体模块或不可达页面的类似弹窗/封面问题。
