# 04: 缺失来源的名称与中文提示

**What to build:** 对确实未安装的来源，导入时保存备份里的来源名称；作品页显示「来源未安装：<名称>」而不是 `mihon.unavailable`，并说明当前只能看本机已保存的章节；章节打开/下载失败给出中文提示，引导用户自行安装扩展。不提供跳转扩展商店的按钮，不自动安装。

**Blocked by:** 03（已安装扩展的导入作品恢复可读）

**Status:** ready-for-agent

- [ ] 导入时把备份 `BackupSource` 的 sourceId → 名称映射持久化到占位条目的 source metadata（可选字段）。
- [ ] 来源名称未知或旧备份缺少名称时，UI 退化为「来源未安装」，不显示内部占位值。
- [ ] 作品页在来源缺失时显示「来源未安装：<名称>」，不显示 `mihon.unavailable`。
- [ ] 作品页说明当前只展示本机已保存的章节；刷新/阅读需要安装扩展。
- [ ] 章节打开失败时显示中文提示「来源未安装，请先安装对应扩展后重试」。
- [ ] 章节下载失败时显示同一类中文提示，不再直接展示英文内部错误。
- [ ] 缺失来源的作品仍保留在 Library，不被隐藏或删除。
- [ ] 不新增「打开扩展商店」按钮，不自动安装扩展。
- [ ] 安装扩展后再次打开作品即可阅读，不需要重启或重新导入。
- [ ] 页面级与导入服务测试覆盖名称持久化、缺失来源标签、中文错误提示与安装后的恢复路径。
