# 图源本地化、下载页简化与 CBZ 下载（local-source-cbz-downloads）

Status: implemented
Date: 2026-11-08

## Problem Statement

漫画读者目前要在三个互不相干的地方管理本地漫画与下载：

- 浏览页第一个视图页签叫「在线源」，但它实际承载的是所有 Source 入口；本地漫画只能通过浏览页的「导入」子视图或设置里的「导入本地漫画」批量登记，扫描结果全部涌进书架，用户无法挑选。
- 下载页每一行都显示「扩展源」「外部来源」（或「直链 · HTTP」）标签；取消下载和重试藏在展开面板里，必须点开行才能操作，而展开本身又容易被误触。
- 设置页的「存储与下载」同时存在「漫画数据位置」和「下载文件夹 / 本地漫画文件夹 / 备份文件夹」三类重叠入口；「漫画数据位置」整行可点会直接弹目录选择器；导入本地漫画的入口与浏览页重复；备份分组藏在「系统与关于」里，与存储相关设置割裂。
- 在线下载只能保存为平铺图片的文件夹，用户想携带、备份或归档单章时没有单文件形态。

用户需要一套更直接的操作路径：本地漫画从「图源」里按需挑选，下载页一眼能取消/重试，存储设置只保留一个位置入口，并且新下载默认得到便于携带的 CBZ 章节包。同时不改变现有 UI 的设计、主题与布局。

## Solution

- 浏览页第一个视图页签「在线源」改名为「图源」；图源列表第一位新增内置「本地图源」，读取 Local source root（`localcomic`），进入后自动扫描并以封面网格展示；只展示、不登记，用户逐部选择加入书架。
- 删除浏览页「导入」子视图与设置里的「导入本地漫画」段，批量导入能力退役。
- 下载页去掉来源标签与展开，行尾直接提供取消（排队/下载中）或重试（失败/已取消）。
- 设置页合并存储入口：「漫画数据位置」改名「存储位置」、整行只读，尾部「变更文件夹」与「打开文件夹」；移除三个子文件夹入口；备份分组搬入「存储与下载」；新增「保存为CBZ压缩包」开关（默认开启）。
- 在线下载默认保存为 `downloads/{source}/{manga}/{chapter}.cbz`；已有文件夹章节保持原样；阅读、重建下载索引、删除与缩略图完整支持 CBZ 章节载体。

## Implementation Decisions

### 图源与导入退役

- 「在线源」→「图源」只改显示文案：简中「图源」、繁中「圖源」；英文基线已是中性「Sources」，其它 locale 已是中性词，不动。保留现有 i18n key 与内部页签枚举名。
- 删除浏览页「导入」子视图：页签枚举值、页面组件、路由与仅它使用的组合测试一并删除；最终可见页签为「图源 → 发现」。
- 若顶层页签枚举中另有已无引用的 legacy「扩展」值，一并删除；「图源」内部的「来源 / 扩展」二级分段保留。
- 图源页签可见性规则不变（功能模块 + 平台在线源能力），不做 iOS 特例。
- 删除设置里的「本地漫画 / 导入本地漫画」段。
- 删除只服务批量导入的服务入口（`importFromRoot` 语义）；保留按单部作品登记的入口（`registerScannedManga` 语义），供本地图源与重建下载索引使用。

### 本地图源（built-in pseudo-source）

- 「本地图源」是图源列表中的内置伪源行，照旧 Mokuro.moe 的做法：不写入 `manga_online_sources`，不由 Extension 提供，不走 Extension 启用/禁用与扩展安装检查。
- 专用偏好开关，默认开启；关闭后行保留、置灰、不可进入，普通 Source 行的开关视觉一致。
- 固定排序第一位，位于「已置顶」分组之上；没有置顶/取消置顶、上移/下移、清除数据、卸载扩展等菜单。
- 行内容：启用开关 + 名称「本地图源」+ 副标题为 `localcomic` 的绝对路径（过长截断）；不显示语言标签。
- 本地图源不出现在 `enabledMangaOnlineSources` 的枚举结果里，因此不参与发现页来源磁贴、热门行与 Manga 全局搜索；它仍参与图源列表自身的搜索过滤。
- 图源列表搜索框占位文案由「搜索在线源」改为「搜索图源」。

### 本地图源页面

- 页面外壳复用现有源浏览页：返回键、左上浮动标题胶囊「本地图源」、搜索框、封面网格；隐藏「热门 / 最新」listing 分段与筛选按钮。
- 每次进入页面都用现有 Local source scanner 扫描 Local source root；不做文件监视、不做增量缓存；扫描期间显示加载态。
- 搜索框在已扫描结果中按标题过滤；网格按标题自然排序。
- 封面沿用 `cover.jpg/jpeg/png`；缺失时用现有占位封面。
- 空态复用现有占位组件：书本图标 + 「尚未发现任何漫画」，不加按钮。
- 扫描失败显示错误占位/提示，而不是空白页。
- 扫描原地读取，不复制、不移动 `localcomic` 中的任何文件。

### 未入库本地作品

- 点网格封面进入作品页。已在书架的作品走现有 Shelf 目标；未入库作品新增第三种作品页目标变体，携带扫描得到的作品路径与章节描述，不要求数据库行。
- 未入库作品页展示封面、标题、章节列表，并提供「加入书架」动作；加入时调用单部作品登记入口原地登记。
- 未入库作品页点章节阅读时，先静默登记该作品再加入书架并打开阅读器；这是用户通过「点开这一章」显式选择该作品。
- 网格不显示「已在书架」角标；已入库作品与未入库作品共用同一封面网格外观。
- 已移出书架（tombstone）但文件仍在的作品照常显示；扫描与展示不清除 tombstone；只有用户显式点击「加入书架」时才清除 tombstone 并重新登记。
- 作品页的封面、章节读取沿用现有 Local source 阅读路径；文件夹章节与 CBZ 章节都可用。

### 下载页

- 下载页的任务卡不再渲染整行来源标签（扩展源 / 外部来源 / 直链 · HTTP）。
- 共享下载任务卡增加「不可展开、无来源标签」模式，仅下载页使用；其它调用点（发现页直链任务、通知对话框、详情页 chips）行为不变。
- 该模式下：不显示展开箭头、不响应整行点击、不持久化展开状态。
- 行尾操作：排队中/下载中显示取消图标；失败/已取消显示重试图标；已完成不显示操作。图标、tooltip 与调用的 service 方法沿用现有展开面板。
- 空态、浮动标题胶囊与滚动收起行为不变。

### 设置页

- 「存储与下载」目的地最终分组顺序：数据存储位置 → 下载 → 备份 → 下载索引。
- 「数据存储位置」段：
  - 「存储位置」行（原「漫画数据位置」）：只读状态行，整行无点击动作；尾部两个按钮「变更文件夹」与「打开文件夹」。
  - 「程序数据位置」行保持只读，行为不变。
  - 「变更文件夹」沿用现有目录选择器、路径校验、切换 Content root、重启提示与错误文案。
  - 「打开文件夹」使用现有 reveal-in-file-manager 原语，打开 Content root 本身；目录不存在时先创建，打开失败复用现有失败提示。
- 移除「下载文件夹 / 本地漫画文件夹 / 备份文件夹」三个状态行；它们来自共享的 Content root 段构建器，因此 SRS 备份页上的同名入口也一并消失。
- 移除「本地漫画 / 导入本地漫画」段。
- 备份分组整组（导入 Mihon 备份、导出 Mihon 备份）从「系统与关于」搬到「存储与下载」，条目文案、启用/置灰状态、导入文件选择器默认目录（Backup directory）不变；「系统与关于」不再保留备份分组。
- 新增「下载」段：开关「保存为CBZ压缩包」，默认开启，副标题说明只影响新开始的下载；偏好存于现有 preferences 体系。
- 「重建下载索引」保持在「下载索引」段，行为不变。
- 全部改动复用现有设置组件、主题与布局，不新增视觉风格。

### CBZ 下载

- 新偏好「保存为CBZ压缩包」默认 true；新安装与升级后的现有用户首次见到该设置时均为开启。
- 生效范围：只影响开启后新开始的下载任务。格式在任务开始运行时确定；排队中的任务在真正开始时读取当时的值；已在运行的任务保持其开始时的格式。
- 开启时，新下载章节的章节载体是 `downloads/{source}/{manga}/{chapter}.cbz`；关闭时沿用 `downloads/{source}/{manga}/{chapter}/` 文件夹。
- 压缩包根目录放平铺、零填充的页图（`001.jpg…`）与 `pages.json`；`pages.json` schema 与文件夹章节相同。
- 章节名净化、同名冲突后缀（`[scanlator]`、` (2)`）、路径长度截断规则与文件夹章节共用。
- 已有完整文件夹章节原样采纳，不转换；切换开关不改变既有章节。
- 下载流程：页图仍先写入 `.staging/{jobId}`，支持续传与页文件 `.tmp` 后改名；`pages.json` 最后写入 staging；随后在同一漫画目录写 `{chapter}.cbz.tmp`，完成后原子改名为最终 `.cbz`。崩溃或取消不会留下可见的半成品。
- 取消下载只清理 staging 与未完成的临时包；最终压缩包只在完成时出现。
- 数据库：`manga_chapter_dirs` 增加显式容器类型列（folder / archive），已有行迁移为 folder；schema v2→v3。现有名称列从「目录名」语义扩展为「容器名」（单段文件夹名或单段压缩包文件名）。
- 章节载体抽象改为种类感知：解析、完整性检查、删除、页访问、缩略图与阅读器都同时支持文件夹与压缩包。
- CBZ 页按需懒解压到缓存目录，复用现有 Local source CBZ 阅读会话；不把整包解压进受管目录。
- 重建下载索引扫描 Download library 时同时枚举子目录与 `.cbz` 文件，从压缩包根读取 `pages.json` 并重新关联映射。
- 删除压缩包章节删除对应文件；删除漫画删除其目录（目录内可含多个 `.cbz`）。
- 互联对端读取下载章节的路径同步支持压缩包容器，或显式跳过压缩包且不崩溃；不得留下运行时会崩的分支。
- 下载任务表不增加格式列；格式不是任务的持久属性，只在任务运行期间生效。

### UI 保真

- 所有新增/修改的 UI 复用现有组件、图标、主题和布局；不重绘、不简化、不引入新的视觉风格。

## Testing Decisions

### 好测试的标准

- 只测试外部行为：磁盘上出现什么文件、压缩包里有什么、书架有哪些行、下载状态如何变化、阅读器能打开哪些页、设置模型输出哪些条目、界面上显示什么文字与按钮。
- 不测试私有辅助函数，不 mock 文件系统，不依赖实现细节。
- 使用真实临时目录与真实 SQLite 数据库；UI 测试通过现有 AppModel/test root 驱动。

### Seams

- **主 seam（唯一新增的测试入口为零）**：现有真实临时目录测试根（`FUSHI_TEST_ROOT` / 测试目录）+ `AppPaths.resolve()` + 真实数据库 + 公共 service（Local source scanner/library/reader、Manga download service、Download library index、Rebuild download index service）。这是仓库现有的最高层 seam，storage-layout 的下载、导入、重建测试都建在它上面。
- **UI surface（复用现有 seam）**：现有 settings schema 测试与页面 widget 测试，在同一个 AppModel/test root 上断言目的地/条目 id、文案、顺序、可见性、行动作；下载页与本地图源页用现有页面 widget 测试 harness。
- 不新增测试框架或新的注入点；如某个页面缺少可注入的打开文件夹/扫描入口，优先复用现有 debug/test 缝，而不是新造 seam。

### Prior art

- 下载存储与映射：`manga_download_service_test`、`download_library_storage_test`、`download_library_index_test`、`rebuild_download_index_service_test`。
- 本地源扫描/读取/登记：`local_source_cbz_scan_test`、`local_source_reader_test`、`local_source_library_test`、`local_source_drop_test`、`manga_page_provider_test`。
- 设置页：`settings_downloads_open_page_subtitle_guard_test`、`storage_content_root_settings_test`、`settings_local_comics_import_test`、`settings_rebuild_download_index_test`、`backup_directory_settings_test`、`sync_settings_visibility_test`。
- 下载页：`downloads_page_test`。
- 浏览页组合：`manga_sources_view_composition_test`（删除或改造成本地图源页面测试）。

### 场景覆盖

- 图源页签显示文案与顺序；导入页签不存在；导入相关组件不再被引用。
- 本地图源行固定第一位、开关默认开/可持久化、副标题为实际路径、关闭后不可进入；不出现在全局搜索与发现枚举中。
- 每次进入触发扫描：新增文件出现、删除文件消失；不复制/移动源文件；空态文案「尚未发现任何漫画」；搜索过滤；自然排序；扫描失败提示。
- 未入库作品页：显式加入书架；点章节自动加入并打开阅读器；已在书架作品走正常作品页；tombstone 作品可见且显式加入后重新登记；无角标。
- 下载页：无来源标签；不可展开；整行不可点；排队/下载中可取消；失败/已取消可重试；已完成无操作；其它页面的任务卡行为不变。
- 设置：标签改名；存储位置行不可点；两个按钮；打开文件夹路径与创建行为；三个文件夹行消失（含 SRS 页）；导入段消失；备份组搬移与顺序；CBZ 开关默认值；重建索引行为不变。
- CBZ：默认开启；新下载生成压缩包且包根有页图与 `pages.json`；关闭后生成文件夹；已有文件夹不被转换；运行中任务格式不变；取消不留半成品；原子改名；阅读器打开；重建索引重新关联；删除文件；缩略图按需解压；互联路径不崩。
- 升级路径：旧库迁移到 schema v3，已有章节映射为 folder。

## Out of Scope

- iOS 特例行为；本项目不做 iOS。
- 把已有文件夹章节批量转换为 CBZ。
- `.tachibk` 导出实现与定时自动备份。
- 书架拖拽导入的旧批量语义：本次随批量导入退役改为只登记被拖入的作品或根目录下的一级作品，不恢复旧的整根扫描。
- 本地图源进入 Manga 全局搜索、发现页来源磁贴或热门行。
- 自动文件监视。
- 已完成下载行的「清除记录/移除」动作。
- 下载暂停/恢复。
- UI 重设计、主题/美术或布局变更。
- 旧 Fushi/my-comic 数据的迁移。
- 非 Windows 平台行为，仅保持可编译。
- 与本次无关的未使用 i18n key 清理。
