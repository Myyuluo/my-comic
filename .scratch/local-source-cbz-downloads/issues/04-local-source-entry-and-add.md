# 04: 本地图源：内置源行、扫描网格与逐部加入书架

**What to build:** 图源列表第一位出现内置「本地图源」，点击后进入自动扫描 `localcomic` 的封面网格；扫描结果只展示、不自动登记，用户点开某部作品并显式「加入书架」后才登记。已移出书架但文件仍在的作品照常显示，显式加入时重新登记；本地图源不出现在 Manga 全局搜索与「发现」页。

**Blocked by:** None（can start immediately）

**Status:** resolved

- [x] 「本地图源」行固定在图源列表第一位、位于「已置顶」分组之上；没有置顶/排序/卸载/清除数据菜单
- [x] 行内有启用开关，默认开启且状态持久化；关闭后行置灰、不可进入；副标题显示 `localcomic` 绝对路径（过长截断），无语言标签
- [x] 点击进入本地图源页面：返回键、左上胶囊「本地图源」、搜索框、封面网格；不显示「热门/最新」分段与筛选按钮
- [x] 每次进入页面都重新扫描 `localcomic`，扫描期间显示加载态；不做文件监视
- [x] 扫描原地读取，不复制、不移动源文件；封面缺失时使用现有占位封面
- [x] 搜索框按标题过滤已扫描结果；网格按标题自然排序
- [x] 空态复用现有占位组件：书本图标 +「尚未发现任何漫画」，不加按钮；扫描失败显示错误提示而不是空白页
- [x] 点封面进入未入库作品页：展示封面、标题与章节列表，提供「加入书架」动作
- [x] 已在书架的作品从本地图源打开时走正常作品页；已移出书架（tombstone）但文件仍在的作品仍显示，显式「加入书架」会清除 tombstone 并重新登记
- [x] 网格不显示「已在书架」角标
- [x] 本地图源不出现在 Manga 全局搜索、发现页来源磁贴与热门行；仍参与图源列表自身的搜索过滤
- [x] 相关 service 与页面 widget 测试覆盖扫描、搜索、排序、空态、加入书架与 tombstone 行为
